💡 Tips for Good Update Notes

🎯
Be Specific

Instead of “make it better”, say “increase the heading font size to 1.5rem”.

🐛
Describe Bugs Clearly

Explain what happens versus what should happen.

📋
Prioritise Changes

List the most important changes first so critical fixes land even if context runs out.

🔄
Iterate

Run multiple update cycles — refine a little at a time for best results.
