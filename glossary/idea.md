tools:
need a central model importer and validator

app idea: an interactive concept explorer
open explore:
ability to search and browse the graph in a usable, navigable way.
path exploration mode:
root nodes with now knowledge dependencies are shown first.
the user can read and/or certify they "know" that node, which then unlocks its children.
the user can also "don't know" a node, which surfaces its parents as new root nodes to explore.
this allows the user to efficiently explore the graph of concepts, starting from the periphery and working inward toward the core.
