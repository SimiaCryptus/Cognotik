Cognitive Task Planning Framework

The central nervous system of Cognotik. It understands high-level goals, formulates intelligent plans, and orchestrates a vast library of tasks to execute complex workflows autonomously.

Core Concepts

Cognitive Modes

Distinct "thinking styles" ranging from linear planning to autonomous, adaptive agents.

Abstract Tasks

A unified interface for specialized tools, from file operations to complex reasoning engines.

Orchestration

Intelligent dependency management and context passing between tasks in a workflow.

Cognitive Modes

Waterfall Mode

Plan-first strategy. Generates a complete, multi-step plan for user review before any execution begins. Best for well-defined goals.

Conversational Mode

Interactive, step-by-step execution. Selects the single best task for the immediate context. Ideal for exploration and debugging.

Adaptive Planning

Autonomous "Think, Act, Reflect" loop. Continuously adapts its plan based on task results. Perfect for ambiguous problems.

Hierarchical Planning

Divide and conquer. Decomposes massive goals into a tree of sub-goals and tasks, managing complex dependencies automatically.
