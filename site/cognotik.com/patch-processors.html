Language-Specific Processors

Pre-configured processors optimized for different languages and syntaxes.

🔷 CStyle

Java, JavaScript, TypeScript, C++, C#, Go, Rust, Swift, Kotlin
Optimized for curly-brace syntax. Tracks bracket nesting depth with weighted scoring for languages with explicit block delimiters.
PatchProcessors.CStyle

🐍 Indentation

Python, YAML, Haskell, F#, CoffeeScript
Reduced bracket matching (only parentheses and square brackets). Larger context window respects indentation-based structure.
PatchProcessors.Indentation

📝 Markdown

Markdown, reStructuredText, plain text, documentation
Disables bracket matching with more lenient fuzzy matching. Ideal for natural language content and documentation.
PatchProcessors.Markdown

🏷️ Markup

HTML, XML, SVG, XAML
Specialized angle bracket matching with higher weight for tags. Smaller context window optimized for markup languages.
PatchProcessors.Markup

🔮 Lisp

Lisp, Scheme, Clojure, Racket
Heavy parenthesis tracking with triple weight. Optimized for deeply nested S-expressions.
PatchProcessors.Lisp

🔚 EndBased

Ruby, Lua, VB.NET, Pascal
Supports optional braces with equal weight for all bracket types. Larger context window for block-end languages.
PatchProcessors.EndBased

🗃️ SQL

SQL, PL/SQL, T-SQL, PostgreSQL
Parenthesis-only bracket matching with stricter fuzzy matching for database query languages.
PatchProcessors.SQL

📊 DataFormat

JSON, TOML, HOCON
Curly and square bracket tracking with higher weights. Disables fuzzy matching for data integrity.
PatchProcessors.DataFormat

💻 Shell

Bash, Zsh, Fish, PowerShell
Full bracket support with fuzzy matching enabled. Standard context window for shell scripts.
PatchProcessors.Shell

⚙️ Config

INI, properties, .env, .conf files
No bracket matching with fuzzy matching enabled. Minimal context for configuration files.
PatchProcessors.Config

Behavior-Specific Processors

Choose based on your precision vs. flexibility requirements.

Processor Fuzzy Matching Snippet Patching Context Size Best For
Strict ✗ Disabled ✗ Disabled 5 lines Critical production code, security-sensitive files
Fuzzy ✓ Balanced (÷4) ✓ 80% threshold 3 lines General-purpose patching, default recommendation
Lenient ✓ Very lenient (÷2) ✓ 60% threshold 2 lines Heavily modified codebases, rapid prototyping

Key Innovations

What makes FuzzyPatchMatcher different from traditional diff/patch tools.

1. Bidirectional Line Linking

Creates a doubly-linked list of lines with forward and backward references, enabling context-aware matching and bidirectional traversal.

2. Multi-Phase Matching

Three-phase approach: Unique line matching → Adjacent line propagation → Recursive subsequence linking. Adapts to code structure organically.

3. Structural Awareness

Tracks bracket nesting depth with weighted scoring. Provides semantic context beyond text matching—distinguishes similar lines in different scopes.

4. Intelligent Fuzzy Matching

Levenshtein distance with structural type checking. Adaptive thresholds scale with line length. Prevents false positives on short lines.

5. Snippet Patching

Handles AI-generated code blocks without explicit diff markers. Three-tier matching: exact → anchor → fuzzy with graceful degradation.

6. Move Detection

Detects when lines have been moved (not just added/deleted) by comparing the ordering of matched lines between source and patch.

kotlin 
// FuzzyPatchMatcher Configuration Options

val processor = FuzzyPatchMatcher(
    // Number of context lines to preserve around changes
    contextSize = 3,

    // Levenshtein distance threshold = lineLength / divisor
    // Lower = stricter matching, Higher = more lenient
    levenshteinThresholdDivisor = 4,

    // Minimum line length to apply fuzzy matching
    // Prevents false positives on short lines
    minLineLengthForFuzzyMatch = 5,

    // Threshold for snippet matching (0.0 - 1.0)
    // null disables snippet patching
    snippetMatchThreshold = 0.8,

    // Require first/last lines to match for snippet patching
    requireAnchorMatch = true,

    // Characters to track for structural awareness
    bracketChars = setOf('(', ')', '{', '}', '[', ']'),

    // Weights for bracket depth calculation
    // Higher weight = more important for matching
    bracketWeights = mapOf(
        '{' to 2, '}' to 2,  // Curly braces weighted higher
        '(' to 1, ')' to 1,
        '[' to 1, ']' to 1
    )
)

// Integration with Cognotik Task Planning

class CodeModificationTask(
    private val processor: PatchProcessor = PatchProcessors.CStyle.processor
) : AbstractTask() {

    override fun execute(context: TaskContext): TaskResult {
        val sourceFile = context.getFile("target.kt")
        val aiPatch = context.getAIResponse()

        // Apply the patch with fuzzy matching
        val modifiedCode = processor.patch(
            sourceFile.readText(),
            aiPatch
        )

        // Write back the modified code
        sourceFile.writeText(modifiedCode)

        return TaskResult.success("Code modified successfully")
    }
}
