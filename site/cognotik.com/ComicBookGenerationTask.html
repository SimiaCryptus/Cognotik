ComicBookGenerationTask

Generate structured comic book scripts and high-fidelity visual strips with character consistency and multi-page orchestration.

Category: Writing Multi-Modal DALL-E / Midjourney Integration

Execution Configuration

Field Type Description
subject * String The subject or scenario to develop into a comic book.
target_pages Int Target number of pages (Default: 5).
art_style String Art style (e.g., 'manga', 'noir', 'cartoon').
style_details String Additional visual guidelines or lighting details.
generate_images Boolean Whether to generate images for each row (Default: true).

Token Usage: High (Multiple LLM calls for script + Image generation tokens).

Task Lifecycle

  1. Script Generation: Uses a smart model to create a ComicScript object containing characters, pages, rows, and frames.
  2. Character Profiling: Extracts visual traits for each character to ensure consistency.
  3. Reference Generation: Generates character sheets to be used as visual context for subsequent panels.
  4. Strip Generation: Iterates through pages and rows, generating composite images for each "strip" using character references and scene descriptions.
  5. Finalization: Packages the script and image links into a comic_book.json workspace file.

Kotlin Boilerplate


val task = ComicBookGenerationTask(
    orchestrationConfig = config,
    planTask = ComicBookGenerationTaskExecutionConfigData(
        subject = "A space western about a lonely robot",
        art_style = "western superhero",
        target_pages = 3
    )
)
