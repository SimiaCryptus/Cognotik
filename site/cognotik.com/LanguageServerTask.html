LanguageServerTask

Leverage the Language Server Protocol (LSP) to provide deep code intelligence, including definitions, references, and diagnostics.

Side-Effect: Read-Only High Latency Multi-Language
Input Configuration

{
  "action": "definition",
  "file": "src/auth/User.ts",
  "line": 14,
  "character": 8
}
→
LSP Response
// Result found
src/models/User.ts:5:1
export class User { ... }

Configuration Parameters

Field Type Description
action * Enum One of: diagnostics, definition, references, hover.
file * String Relative path to the source file.
line Integer 0-indexed line number (required for definition/hover).
character Integer 0-indexed character offset (required for definition/hover).

Supported Languages

Python (.py) JavaScript/TypeScript (.js, .ts) Kotlin (.kt) Java (.java) C/C++ (.c, .cpp) Go (.go) Rust (.rs) Bash (.sh)
Ready to connect to Language Server...

Kotlin Integration


val lspTask = LanguageServerTask(
    action = LspAction.Definition,
    file = "src/services/PaymentService.kt",
    line = 45,
    character = 12
)

val result = agent.execute(lspTask)
println("Definition found at: ${result.location}")
