Council Mode

+

+ The Boardroom of AI. A multi-agent consensus engine where distinct personas collaborate, debate, and vote to drive complex decision-making. +

+
+ +
+

Core Mechanics

+
+
+ +

Diverse Personas

+

Simulate a team of experts (e.g., CEO, CTO, QA) who maintain separate goals and reasoning states throughout the session.

+
+
+ +

Democratic Process

+

Agents nominate tasks based on their domain expertise, then vote to prioritize the most critical actions for the current iteration.

+
+
+ +

Iterative Refinement

+

Execution results are fed back to all council members, allowing them to update their strategies and adapt to new information.

+
+
+
+ +
+

Workflow

+
+

1. Assembly

+

+ The system initializes the configured council members. By default, this includes: +

    +
  • CEO: Focuses on high-level goals and business value.
    • +
  • CTO: Focuses on technical feasibility and architecture.
    • +
  • QA: Focuses on testing and quality assurance.
    • +
+

+ +

2. Nomination

+

+ Given the user's goal and current project context, each member independently proposes a set of tasks they believe should be done next. +

+ +

3. Voting

+

+ The council reviews all nominations. Members cast votes for tasks that align with their specific objectives. This filtering process ensures that only the most robust and agreed-upon tasks proceed to execution. +

+ +

4. Execution & Reporting

+

+ Winning tasks are executed by the system. The results are shared with the council to update their internal states. A detailed transcript of the session, including nominations and voting logic, is generated for review. +

+
+
+ +
+

Configuration

+

+ Council Mode is highly configurable. You can define custom personas to suit your specific project needs. +

+ 

+val councilConfig = CouncilModeConfig(
+    council = listOf(
+        ProjectManagerStrategy(
+            name = "Product Owner", 
+            description = "Prioritizes user features and roadmap alignment."
+        ),
+        ProjectManagerStrategy(
+            name = "Security Architect", 
+            description = "Ensures all code meets security standards."
+        ),
+        ProjectManagerStrategy(
+            name = "DevOps", 
+            description = "Focuses on deployment and infrastructure."
+        )
+    ),
+    maxIterations = 10,
+    maxTasksPerIteration = 3
+)
