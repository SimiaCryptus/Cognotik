# Mechanics Design: Cyberpunk Stealth ## Core Mechanic: Network Intrusion - **Action:** Player connects to nodes via line-of-sight. - **System:** Connection speed depends on distance and firewall level. - **Risk:** Staying connected too long triggers "Trace" protocol. ## Progression System - **XP Source:** Successful hacks, undetected extraction. - **Unlocks:** - Lvl 2: Signal Booster (Range +20%) - Lvl 5: Ghost Protocol (Invisibility for 5s) ## Balance Analysis - **Skill Expression:** High. Timing and positioning are critical. - **Luck Factor:** Low. Deterministic AI patterns. - **Strategy:** Multiple paths to objective (Stealth vs. Brute Force).
