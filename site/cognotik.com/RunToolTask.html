RunTool Task

Seamlessly integrate external command-line tools into your AI agent's workflow. Orchestrate builds, deployments, and system operations with precision.

Core Capabilities

Tool Discovery

Automatically locates installed tools (Git, Docker, Java, etc.) on the host system using the PATH environment.

Argument Injection

Dynamically constructs command arguments based on task context and upstream dependencies.

Process Isolation

Executes commands in specific working directories to maintain file system context and safety.

Stream Capture

Real-time capture of standard output (stdout) and error streams (stderr) for detailed analysis.

Broad Support

Native support for 20+ tools including Git, Docker, Kubernetes, AWS CLI, Gradle, Maven, and Python.

Exit Code Handling

Validates execution success via exit codes, allowing for automated retry logic or error handling.
