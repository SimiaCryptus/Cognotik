Execution Configuration

Field Type Description
files * List<String> The image file to be created. Must be a single file ending in .png, .jpg, or .jpeg.
task_description String Detailed description of the image including subject, style, composition, and mood.
related_files List<String> Reference images or style guides to provide visual context to the generator.
task_dependencies List<String> List of task IDs that must complete before this generation starts.

Task Lifecycle

  1. Validation: Ensures exactly one output file is specified with a valid image extension.
  2. Context Loading: Reads any reference images specified in related_files.
  3. Prompt Engineering: Combines the task description with content from related files and results from prior tasks.
  4. Agent Execution: Dispatches to ImageProcessingAgent to generate the asset and an optimized prompt.
  5. Persistence: Saves the generated image to the workspace and provides a download link in the UI.

Kotlin Usage

Invoke via UnifiedHarness for headless automation:

import com.simiacryptus.cognotik.plan.tools.file.ImageGenerationTask.Companion.GenerateImage
import com.simiacryptus.cognotik.plan.tools.file.ImageGenerationTask.GenerateImageTaskExecutionConfigData

harness.runTask(
    taskType = GenerateImage,
    typeConfig = TaskTypeConfig(),
    executionConfig = GenerateImageTaskExecutionConfigData(
        files = listOf("output/branding/logo_v1.png"),
        task_description = "Minimalist tech logo, vector style, blue and silver",
        related_files = listOf("docs/brand_guidelines.pdf")
    ),
    workspace = File("./project-assets"),
    autoFix = true
)

Prompt Segment

The following instruction is provided to the orchestrator:

GenerateImage - Create high-quality images using AI generation models.
  * Specify a single output file path (png, jpg, or jpeg).
  * Provide a detailed task_description covering style, composition, and mood.
  * Use related_files to provide visual context or style references.
  * Useful for UI mockups, illustrations, and visual assets.
