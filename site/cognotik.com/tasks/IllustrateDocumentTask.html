Task Lifecycle

+
+
+

1. Document Analysis

+

The task reads the source file and uses an LLM to identify high-impact locations for visual aids. It generates specific prompts and filenames for each suggestion.

+
+
+

2. Image Generation

+

Using the ImageProcessingAgent, it creates assets based on the analysis and any composerDirective provided. Images are saved directly to the document's directory.

+
+
+

3. Patch Integration

+

The task generates diff patches to insert ![]() or <img> tags. If autoFix is enabled, these are applied immediately; otherwise, they await user approval.

+
+
+

+  - Configure maximum number of images (default: 5)
+  - Choose image format (png/jpg)
+  - Analyzes document structure and content
+  - Generates contextually appropriate images
+  - Saves images with descriptive names in the same folder
+  - Optionally inserts image references at appropriate locations
