Configuration Parameters

Field Type Description
search_pattern * String The search pattern (substring or regex) to look for in the files.
is_regex Boolean Whether the search pattern is a regex (true) or a substring (false). Default: false.
context_lines Int Number of context lines to include before and after each match. Default: 2.
input_files List<String> Glob patterns for files to be searched (e.g., ["src/**/*.kt"]).
extractContent Boolean Extract text from non-text files (PDF, HTML, etc.) before searching.

Task Lifecycle

  • Initialization: Validates that search_pattern is not blank and context_lines is non-negative.
  • File Discovery: Resolves glob patterns against the workspace root, filtering out LLM-ignored files.
  • Search Execution: Reads files (with optional content extraction) and applies the regex/substring pattern.
  • Context Grouping: Merges overlapping context windows into contiguous display blocks to minimize redundancy.
  • Rendering: Generates a tabbed UI in the session view, separating the summary from individual file results.
