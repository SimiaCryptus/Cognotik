Configuration Parameters

Field Type Description
report_topic* String The subject or topic of the report.
report_type String Type of report (e.g., status_update, quarterly_review, incident_report, performance_analysis).
target_audience String Target audience (e.g., executives, stakeholders, team_members).
time_period String Time period covered (e.g., Q1 2024, Last 30 days).
key_metrics List<String> Specific KPIs to include in the analysis.
data_points Map<String, Any> Raw statistics or data points to analyze.
include_trend_analysis Boolean Compare to previous periods. Default: true.
include_visualizations Boolean Include chart/table descriptions. Default: true.
include_executive_summary Boolean Include high-level dashboard. Default: true.
include_recommendations Boolean Include actionable steps. Default: true.
include_comparative_analysis Boolean Include benchmarks/competitors. Default: true.
include_risk_assessment Boolean Include risk and mitigation section. Default: true.
tone String Tone (e.g., formal, analytical, professional). Default: professional.
target_word_count Int Target length for the complete report. Default: 2000.
revision_passes Int Number of LLM editing passes (0-5). Default: 1.
related_files List<String> Context files to incorporate.
input_files List<String> Glob patterns for source data (e.g., **/*.json).

The Industrial Generation Lifecycle

1. Data Analysis

Analyzes provided metrics and data points, determining trends (increasing/decreasing) and significance levels.

2. Outline Creation

Structures the report into logical sections based on the topic and audience requirements.

3. Content Generation

Iteratively writes each section, maintaining context from previous chapters to ensure narrative flow.

4. Strategic Recommendations

Synthesizes findings into prioritized, actionable steps with rationale and impact estimates.

5. Risk Assessment

Identifies operational, financial, or technical risks and proposes mitigation strategies.

6. Revision & Polish

Performs editorial passes to ensure tone consistency and professional formatting.

7. Final Assembly

Compiles all sections, adds metadata, and generates the final Markdown artifact with download links.

Direct Instantiation


val reportTask = ReportGenerationTask(
    orchestrationConfig = config,
    planTask = ReportGenerationTask.ReportGenerationTaskExecutionConfigData(
        report_topic = "Annual Security Audit",
        report_type = "incident_report",
        target_audience = "board_of_directors",
        include_risk_assessment = true,
        revision_passes = 2,
        input_files = listOf("docs/security/*.md", "logs/audit_summary.json")
    )
)
