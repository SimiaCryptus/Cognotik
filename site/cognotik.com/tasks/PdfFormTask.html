Type Configuration (Static)

Field Type Description
template_file* String Path to the PDF template file used for all executions of this task type.
resultTemplate String Template for the success message. Supports {output_file} and {count}.

Execution Configuration (Runtime)

Field Type Description
output_file String The destination path for the filled PDF. Defaults to filled_form.pdf.
fields Map<String, String> Manual overrides for field names to values.
flatten Boolean If true, flattens the form fields to make them read-only. Default: true.

Task Lifecycle

  1. Initialization: Loads the PDF template specified in TypeConfig and inspects the AcroForm structure.
  2. Context Analysis: If an LLM is available, the task sends the conversation history and the list of available PDF fields to the model to extract relevant data.
  3. Data Merging: Merges LLM-extracted fields with manual overrides provided in ExecutionConfig.
  4. PDF Generation: Uses Apache PDFBox to populate fields, optionally flattens the document, and saves it to the workspace.

Error Handling

If fields specified in the configuration are not found in the PDF template, the task logs a warning but continues processing other fields.

Embedded Execution (UnifiedHarness)

To invoke this task programmatically using the Cognotik engine:


import com.simiacryptus.cognotik.apps.general.UnifiedHarness
import com.simiacryptus.cognotik.plan.tools.file.PdfFormTask
import java.io.File

val harness = UnifiedHarness(serverless = true).apply { start() }

val typeConfig = PdfFormTask.PdfFormTypeConfig(
    template_file = "templates/nda_template.pdf"
)

val executionConfig = PdfFormTask.PdfFormExecutionConfig(
    output_file = "output/signed_contract.pdf",
    fields = mapOf("SignerName" to "John Doe"),
    flatten = true
)

harness.runTask(
    taskType = PdfFormTask.PdfForm,
    typeConfig = typeConfig,
    executionConfig = executionConfig,
    workspace = File("./my-project")
)
