Configuration Parameters

FieldTypeDescription
files * List<String> The HTML presentation file to be created (must end with .html).
task_description String Topic, key points, target audience, and desired style.
generate_images Boolean Whether to generate AI images for key slides (Default: false).
max_images Int Maximum number of images to generate (1-10, Default: 5).

Task Lifecycle

1. Initialization: Validates file extensions and image dimensions (256px - 2048px).
2. Content Generation: Uses ParsedAgent to create a structured PresentationStructure with HTML sections and speaker notes.
3. Visual Assets: If enabled, ImageProcessingAgent generates slide-specific visuals.
4. Styling & Assembly: Generates custom CSS based on content and bundles Reveal.js dependencies.
