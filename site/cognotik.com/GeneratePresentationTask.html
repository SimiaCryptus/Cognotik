Configuration Parameters

Field Type Description
files * List<String> The HTML presentation file to be created (must end with .html).
related_files List<String> Reference materials or existing presentations for context.
task_description String Topic, key points, target audience, and desired style.
generate_images Boolean Whether to generate AI images for key slides (Default: false).
image_width / height Int Dimensions for generated images (256px - 2048px, Default: 1024).
max_images Int Maximum number of images to generate (1-10, Default: 5).

Task Lifecycle

1. Initialization: Validates file extensions and image dimensions (256px - 2048px).
2. Content Generation: Uses ParsedAgent to create a structured PresentationStructure with HTML sections and speaker notes.
3. Visual Assets: If enabled, ImageProcessingAgent generates slide-specific visuals.
4. Styling & Assembly: Generates custom CSS based on content and bundles Reveal.js dependencies.

Embedded Execution (Headless)

Invoke this task programmatically using the UnifiedHarness for automated documentation or reporting.


import com.simiacryptus.cognotik.plan.tools.file.GeneratePresentationTask
import com.simiacryptus.cognotik.plan.tools.file.GeneratePresentationTask.Companion.GeneratePresentation

val executionConfig = GeneratePresentationTask.GeneratePresentationTaskExecutionConfigData(
        files = listOf("presentation.html"),
        task_description = "Deep dive into Cognotik architecture",
        generate_images = true,
        max_images = 5
)

// Run via the UnifiedHarness
harness.runTask(
    taskType = GeneratePresentation,
    typeConfig = GeneratePresentationTask.GeneratePresentationTaskTypeConfig(),
    executionConfig = executionConfig,
    workspace = File("./docs/presentations"),
    autoFix = true
)
