Configuration Parameters

Field Type Description
files List<String> Target files to modify or create.
related_files List<String> Additional files provided as context for the AI.
modifications * Any Specific modifications to be made to the files (Prompt).
extractContent Boolean Whether to read and provide file content to the AI.
includeGitDiff Boolean If true, includes the current git diff with HEAD for context.
task_description String High-level goal of the task.

Task Lifecycle

  1. Context Preparation: Gathers content from files, related_files, and git diffs.
  2. AI Execution: Sends instructions to the LLM using a specialized system prompt for diff generation.
  3. Instrumentation: The response is parsed for diff blocks and instrumented with "Apply" links.
  4. Review/Apply: Changes are either auto-applied or presented for manual approval.

FileModificationTask

Create new files or modify existing code with AI-powered assistance, featuring precise diff-based editing and syntax validation.

Category: File Side-Effect: Destructive Auto-Fix Supported
⚙️ FileModificationTaskExecutionConfigData
{
  "files": ["src/Service.kt"],
  "task_description": "Add calculateTax method",
  "includeGitDiff": true
}
→
👁️ Proposed Changes (UI)
### src/Service.kt
 class Service {
+   fun calculateTax(amount: Double) = amount * 0.15
 }
Field Type Description
files List<String> Target files to modify or create.
related_files List<String> Additional files provided as context for the AI.
includeGitDiff Boolean If true, includes the current git diff with HEAD for context.
task_description * String Natural language instructions for the modification.
task_dependencies List<String> List of task descriptions this task depends on.

Task Lifecycle

  1. Context Preparation: Gathers content from files, related_files, and task_dependencies.
  2. AI Execution: Sends instructions and context to the LLM using a specialized system prompt for diff generation.
  3. Instrumentation: The response is parsed for diff blocks and instrumented with "Apply" links.
  4. Review/Apply: Changes are either auto-applied (if autoFix is enabled) or presented for manual approval.

Embedded Invocation

Use the UnifiedHarness to run this task programmatically:


val executionConfig = FileModificationTaskExecutionConfigData(
    files = listOf("README.md"),
    modifications = "Update the architecture section based on src/main.",
    extractContent = true,
    task_description = "Generate Documentation"
)
harness.runTask(
    taskType = TaskType.FileModificationTask,
    executionConfig = executionConfig,
    workspace = projectDir,
    autoFix = true
)
            
// Registering the task in OrchestrationConfig
val config = OrchestrationConfig(
    tasks = listOf(
        FileModificationTask.FileModification.toConfig(
            files = listOf("src/main.kt"),
            task_description = "Add error handling to the main loop"
        )
    )
)
