Configuration Parameters

Field Type Description
subject_task_id * String The ID of the task whose reasoning process should be reflected upon.
reflection_aspects List<String> Aspects to evaluate: assumptions, biases, alternatives, confidence, completeness, logic.
input_files List<String> Glob patterns (e.g. **/*.kt) for files to be used as context.
reflection_questions List<String> Additional context or specific questions to guide the reflection.
include_file_context Boolean Whether to include file content in the analysis. Default: true.
suggest_improvements Boolean Whether to suggest actionable improvements. Default: true.
identify_gaps Boolean Identify knowledge gaps and uncertainties. Default: true.
evaluate_confidence Boolean Evaluate the confidence level of conclusions. Default: true.

Task Process Lifecycle

  1. Initialization: Validates the subject_task_id and ensures the target task has a valid result in the execution state.
  2. Context Gathering: Aggregates prior code context, specific input files via glob matching, user messages, and custom reflection questions.
  3. LLM Analysis: Uses a specialized ParsedAgent to perform a structured critique based on the selected reflection_aspects.
  4. Synthesis: Generates a ReflectionAnalysis object containing assumptions, biases, and actionable improvement suggestions.

💻 Kotlin Implementation

import com.simiacryptus.cognotik.plan.TaskType
import com.simiacryptus.cognotik.plan.tools.reasoning.MetaCognitiveReflectionTask.Companion.MetaCognitiveReflection
import com.simiacryptus.cognotik.plan.tools.reasoning.MetaCognitiveReflectionTask.MetaCognitiveReflectionTaskExecutionConfigData
import com.simiacryptus.cognotik.plan.tools.TaskTypeConfig

// 1. Define the Job Configuration
val executionConfig = MetaCognitiveReflectionTaskExecutionConfigData(
    subject_task_id = "task_123", // ID of the task to analyze
    reflection_aspects = listOf("assumptions", "biases", "logic"),
    input_files = listOf("src/main/kotlin/**/*.kt"),
    reflection_questions = listOf("Is the concurrency model sound?"),
    suggest_improvements = true
)

// 2. Run via UnifiedHarness
harness.runTask(
    taskType = MetaCognitiveReflection,
    typeConfig = TaskTypeConfig(), // Default static config
    executionConfig = executionConfig,
    workspace = File("./my-project"),
    autoFix = true
)
