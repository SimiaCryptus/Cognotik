JdbcSessionTask

Execute stateful SQL queries via JDBC with automatic Markdown table rendering, session persistence, and multi-driver support.

Category: Session Side-Effect: External DB Stateful
⚙️ TaskConfig.json 
{
  "url": "jdbc:h2:mem:testdb",
  "sessionId": "analytics-run-01",
  "sql": [
    "CREATE TABLE users (id INT, name VARCHAR(255))",
    "INSERT INTO users VALUES (1, 'Alice')",
    "SELECT * FROM users"
  ],
  "closeSession": false
}
→
👁️ Session UI Output

✔ SQL execution finished.

Execution Configuration

Field Type Description
url * String JDBC Connection URL. Required for new sessions.
sql * List<String> A list of SQL statements to execute in sequence.
sessionId String Identifier to reuse an existing connection for transactions or subsequent queries.
user / password String Database credentials.
driver String Optional JDBC Driver Class Name. Auto-detected for H2, MySQL, and Postgres.
driver String Optional JDBC Driver Class Name. Auto-detected for H2, MySQL, and Postgres.
closeSession Boolean If true, closes the connection after this task completes. Default: false.

Task Lifecycle

  • Initialization: Checks for an existing SessionState using the sessionId. If invalid or missing, it instantiates the driver (auto-detecting H2, MySQL, or Postgres if not specified) and establishes a new connection.
  • Execution: Iterates through the sql list. For each statement:
    • Logs the query to the session transcript.
    • Executes the statement via the JDBC connection.
    • If a ResultSet is returned, it is converted into a Markdown table (limited to 100 rows).
    • If no result set, it reports the updateCount.
  • Cleanup: If closeSession is enabled, the connection is closed and removed from the active session registry.

Prompt Injection

The following context is injected into the LLM to inform it of available database sessions:

JdbcSession - Execute SQL queries via JDBC in a stateful session.
** Specify the `url`, `user`, and `password` to start a new session.
** Use `sessionId` to reuse an existing connection for transactions or subsequent queries.
** Provide a list of `sql` statements to execute.
