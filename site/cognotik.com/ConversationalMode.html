Conversational Mode

The Partner. An interactive, context-aware agent that collaborates with you step-by-step, maintaining history and executing tools on demand.

Core Capabilities

Interactive Dialogue

Operates in a continuous loop, allowing for real-time feedback, clarification, and iterative problem solving.

Dynamic Tool Selection

Intelligently selects the best tool for the job from the available task library based on your natural language request.

Expansion Syntax

Power-user syntax to spawn parallel agents or define execution sequences directly from the chat prompt.

How It Works

Conversational Mode is designed to feel like a natural extension of your thought process. Unlike batch processing modes, it maintains a persistent Session object that stores conversation history and state.

When you send a message:

  1. The system analyzes your request against the available Task Library.
  2. It selects the most appropriate task (e.g., FileSearchTask, RunCodeTask).
  3. It executes the task, often using a "Think, Act" loop for complex tools.
  4. The output is returned to the chat, and the context is updated.

Advanced: Expansion Syntax

Automate repetitive workflows without writing scripts using special syntax in your prompt.

Parallel Execution
@[option1|option2]
Spawns separate agents for each option simultaneously.
Sequential Execution
@{step1 -> step2}
Executes step 1, then passes the context to step 2.
Range Expansion
@(1..5)
Iterates through a numerical range.

Topic Memory

Conversational Mode doesn't just remember text; it understands entities. After each interaction, it scans the response for key topics (like file names, class names, or concepts) and indexes them.

Automatic Indexing

If the AI lists several files in a response, it groups them under a topic like {Files}.

Recall Syntax

You can reference these groups later using @{Files} to automatically expand your next command to apply to all those items.
