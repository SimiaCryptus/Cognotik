Task Lifecycle

+
    +
  • Initialization: Loads context from text and files. Optionally imports an existing GraphSON file.
    • +
  • Chunking: Large contexts are split into 4000-character chunks to fit model windows.
    • +
  • Reasoning Loop: +
      +
    • Agent reviews current graph state and context chunk.
      • +
    • Agent proposes ADD_NODE, ADD_EDGE, or MERGE_NODES actions.
      • +
    • Actions are validated against the schema and applied to the TinkerGraph.
      • +
    +
    • +
  • Visualization: Generates Mermaid diagrams at each step for real-time UI feedback.
    • +
  • Export: Final state is saved as a standard GraphSON JSON file.
    • +
