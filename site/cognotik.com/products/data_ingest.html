DataIngest

Iteratively parse unstructured logs into structured data.

File Automation

The DataIngest task automates the creation of regex parsers for log files. It uses Large Language Models (LLMs) to intelligently discover patterns in your data, iteratively refining its understanding until a coverage threshold is met.

Key Features

Pattern Discovery

Automatically samples data to discover regex patterns using LLM, identifying structure in chaos.

Iterative Refinement

Iteratively targets residual (unparsed) data until the specified coverage threshold is met.

Structured Output

Streams large files to produce JSONL, CSV, and Index artifacts for easy consumption.

Configuration

Configure the task using the following parameters in your plan:

Parameter Type Default Description
input_files List<String> Required File patterns to ingest (e.g. **/*.log). Supports glob patterns.
sample_size Int 1000 Number of lines to sample for pattern discovery.
max_iterations Int 10 Maximum number of discovery iterations to run.
coverage_threshold Double 0.95 Stop discovery when this percentage of the sample is covered (0.0 - 1.0).

Output Artifacts

data.jsonl

The extracted data in JSON Lines format. Each line is a valid JSON object.

data.csv

A CSV representation of the extracted data for spreadsheet analysis.

index.csv

An index file mapping extracted records back to the source file and byte offsets.

patterns.json

The registry of discovered Regex patterns and their field mappings.
