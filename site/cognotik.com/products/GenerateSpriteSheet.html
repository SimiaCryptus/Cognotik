GenerateSpriteSheet

Generate a sprite sheet and associated JSON metadata

Category: Writing

Overview

Creates game assets by generating a sprite sheet image and extracting coordinate data.

  • Generates visual sprite sheet using AI image models
  • Analyzes the generated image to find sprite bounding boxes
  • Exports standard JSON metadata for game engine integration

Configuration

Below is the configuration schema for the GenerateSpriteSheet task type.

YAML Example
- task_type: GenerateSpriteSheet
  task_description: "A pixel art warrior walking animation, 4 frames, side view"
  files: 
    - "assets/sprites/warrior.png"
  metadata_file: "assets/sprites/warrior.json"

Parameters

Field Type Description Required
files List<String> The sprite sheet image file to be created (relative path, must end with .png) Yes
metadata_file String The JSON metadata file to be created (relative path, must end with .json) Yes
task_description String Detailed description of the sprites to generate (e.g., 'A pixel art warrior walking animation, 4 frames, side view') No
task_dependencies List<String> List of task IDs that this task depends on No
