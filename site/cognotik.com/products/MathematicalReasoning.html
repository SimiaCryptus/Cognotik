Capabilities

Rigorous Mathematical Proofs

Uses path search to solve mathematical problems through rigorous step-by-step reasoning.

Path Search & Backtracking

Explores multiple solution paths when needed and backtracks when encountering dead ends to find the optimal solution.

Atomic Verification

Breaks down complex problems into verifiable atomic steps. Each step includes justification and is validated for correctness.

MathJax / LaTeX Support

Generates human-readable mathematical proofs with full LaTeX rendering support for complex notation.

Multi-Domain Support

Capable of handling problems in algebra, calculus, number theory, geometry, linear algebra, and more.

Task Configuration

Parameters for the MathematicalReasoning task type.

problem_statement
Required The mathematical problem or theorem to solve/prove.
goal
The goal or target result (e.g., 'prove equality', 'find x', 'simplify expression').
domain
Mathematical domain (e.g., 'algebra', 'calculus', 'number_theory'). Default: general.
given_information
List of known facts, axioms, or given information.
max_depth
Maximum depth of reasoning steps (1-100). Default: 20.
max_alternatives
Maximum number of alternative paths to explore (1-10). Default: 3.
detail_level
Level of detail in explanations ('brief', 'standard', 'detailed'). Default: standard.

Example Usage

JSON Configuration 
{
  "type": "MathematicalReasoning",
  "data": {
    "problem_statement": "Prove that for all integers n, if n^2 is even, then n is even.",
    "goal": "Prove the statement by contrapositive",
    "domain": "number_theory",
    "detail_level": "detailed",
    "max_depth": 15
  }
}
