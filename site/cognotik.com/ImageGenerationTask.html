ImageGenerationTask

Creates high-fidelity images from text descriptions using AI models. Supports context-aware generation using reference files and previous task outputs.

Execution Configuration

Field Type Description
files * List<String> The image file to be created. Must be a single file ending in .png, .jpg, or .jpeg.
task_description String Detailed description of the image including subject, style, composition, and mood.
related_files List<String> Reference images or style guides to provide visual context to the generator.
task_dependencies List<String> List of task IDs that must complete before this generation starts.

Task Lifecycle

  1. Validation: Ensures exactly one output file is specified with a valid image extension.
  2. Context Loading: Reads any reference images specified in related_files.
  3. Prompt Engineering: Combines the task description with content from related files and results from prior tasks.
  4. Agent Execution: Dispatches to ImageProcessingAgent to generate the asset and an optimized prompt.
  5. Persistence: Saves the generated BufferedImage to the workspace and provides a download link in the UI.

Kotlin Usage

// Adding to OrchestrationConfig
val config = OrchestrationConfig(
    tasks = listOf(
        ImageGenerationTask.GenerateImage.create(
            files = listOf("output/logo.png"),
            task_description = "Minimalist tech logo, vector style"
        )
    )
)
