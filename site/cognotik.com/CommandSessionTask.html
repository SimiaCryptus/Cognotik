Command Session Task

Maintain persistent, stateful terminal sessions for complex workflows. Interact with REPLs, manage environment variables, and execute multi-step command sequences with full context retention.

Core Capabilities

State Persistence

Variables, working directories, and process states persist between inputs, enabling complex multi-step logic.

Interactive REPLs

Native support for interactive interpreters like Python, Node.js, or custom shells that require state retention.

Session Reuse

Connect to existing sessions via sessionId to continue workflows, debug, or share context across tasks.

TTY Emulation

Full pseudo-terminal (PTY) support allows execution of tools that demand a TTY, such as interactive CLIs.

Lifecycle Management

Automatic cleanup of idle sessions and zombie processes ensures efficient resource usage.

Stream Monitoring

Real-time asynchronous capture of stdout and stderr allows the agent to react to output immediately.

Task Simulator

Using the same ID preserves state.

When to Use

Interactive Scripting

Execute Python or Ruby scripts line-by-line to analyze data, debug code, or interact with libraries dynamically.

Environment Setup

Set environment variables, change directories, or activate virtual environments that must persist for subsequent commands.

Stateful Workflows

Perform complex build or deployment processes where the output of step A (e.g., a generated token) is needed in step B.
