CommandSessionTask

Execute commands in a stateful, interactive terminal session. Maintains environment persistence, supports TTY allocation, and manages long-running process lifecycles.

Category: Session Stateful TTY Supported

Execution Configuration

Field Type Description
command List<String> The command to start the interactive session. Defaults to ["bash", "-i"].
inputs List<String> Sequential commands to send to the session's standard input.
sessionId String? Optional ID to reuse an existing session. Enables state persistence across multiple task executions.
timeout Long Maximum time (ms) for commands to finish. Default: 30000.
idle_timeout Long Maximum time (ms) to wait for output after a command. Default: 2000.
tty Boolean If true, uses pty4j to allocate a pseudo-terminal. Required for TTY-aware applications.

Task Lifecycle

  1. Session Resolution: Checks if a sessionId is provided and active. If not, it initializes a new Process or PtyProcess.
  2. Output Monitoring: Spawns a daemon thread to continuously read the process's inputStream into a thread-safe buffer.
  3. Command Execution: Iterates through inputs, writing each to the process outputStream and waiting for output based on idle_timeout.
  4. Cleanup: Inactive or dead processes are automatically purged from the global session registry to prevent resource leaks.

Kotlin Boilerplate

Orchestration Setup
val config = CommandSessionTaskExecutionConfigData(
    command = listOf("python3", "-i"),
    inputs = listOf(
        "import os",
        "print(os.getcwd())"
    ),
    sessionId = "python-env",
    tty = false
)

val task = CommandSessionTask(orchestrationConfig, config)
