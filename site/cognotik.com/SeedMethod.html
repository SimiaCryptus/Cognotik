Available Seed Methods

The SeedMethod enum provides various providers for URL discovery:

Method Provider Description
GoogleSearch Native Direct Google Search integration.
SearchIO_Google_Search SearchAPI.io Standard organic search results via SearchAPI.
SearchIO_Google_Scholar SearchAPI.io Academic papers and citations.
SearchIO_Amazon SearchAPI.io Product discovery on Amazon.
DirectUrls Internal Bypasses search; uses provided URLs directly.

SeedItem Structure

Field Type Description
link String The target URL to be crawled.
title String The title or anchor text of the discovery.
relevance_score Double Ranking score (1-100) for prioritization.

Lifecycle of a Seed Strategy

  1. Factory Creation: The SeedMethod enum acts as a factory, creating a SeedStrategy instance based on the user and task context.
  2. Item Retrieval: The strategy executes getSeedItems(), which may involve network calls to search providers or parsing local config.
  3. Filtering: Results are filtered based on EnabledStrategy logic and relevance scores.
  4. Injection: Discovered SeedItem objects are passed to the CrawlerAgentTask to begin the scraping phase.

Kotlin Implementation

Registering a seed method within an orchestration flow:


val config = CrawlerTaskExecutionConfigData(
    seed_method = SeedMethod.SearchIO_Google_Search,
    query = "Cognotik documentation"
)

val strategy = SeedMethod.SearchIO_Google_Search.createStrategy(
    task = crawlerTask,
    user = currentUser
)

val items = strategy.getSeedItems(config, orchestrationConfig)
