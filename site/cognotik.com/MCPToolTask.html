MCPToolTask

Execute tools from Model Context Protocol (MCP) servers with robust connection management, automatic tool discovery, and configurable retry logic.

Category: Online Side-Effect: Variable Auto-Retry Supported

Execution Configuration

Field Type Description
server_name String The name of the MCP server to connect to. Defaults to default_server if omitted.
tool_name String The specific tool to execute on the target MCP server. Required for execution.
tool_arguments Map<String, Any> JSON object containing arguments required by the tool.
timeout_seconds Integer Execution timeout. Defaults to 30s.

Type Configuration (Static)

Field Default Description
default_server null Fallback server name if not provided in execution config.
default_timeout 30 Default timeout in seconds.
auto_retry false Automatically retry on network or timeout errors.
generate_transcript true Whether to generate a detailed Markdown transcript of the execution.
max_retries 3 Maximum number of retry attempts.
retry_delay_ms 1000 Initial delay before the first retry.
exponential_backoff true Use 2^(n-1) delay strategy for retries.

Lifecycle Process

  1. Registry Lookup: Retrieves the MCP client for the specified server_name.
  2. Connection: Establishes transport connection if not already active.
  3. Discovery: Validates tool_name against the server's advertised tool list.
  4. Execution: Dispatches the request with arguments and monitors the timeout.
  5. Recovery: If auto_retry is enabled, handles transient failures with backoff.

Prompt Segment

The following context is injected into the LLM when this tool is available:


MCPTool - Execute tools from Model Context Protocol (MCP) servers
  ** Specify the MCP server name and tool to execute
  ** Provide tool arguments as a JSON object
  ** Configure timeout and retry behavior
  ** Supports integration with external MCP-compatible services

Kotlin Boilerplate


val task = MCPToolTask(
    orchestrationConfig = config,
    executionConfig = MCPToolTaskExecutionConfigData(
        server_name = "my-mcp-server",
        tool_name = "calculate_metrics",
        tool_arguments = mapOf("data" to listOf(1, 2, 3))
    )
)
