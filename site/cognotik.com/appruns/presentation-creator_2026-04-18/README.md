# Presentation Creator

  An AI-powered tool for creating and updating presentations from notes.

  ## How to Use

  ### Creating a New Presentation
  1. Enter your presentation notes in the **Notes** tab
  2. Click **Draft Presentation** to generate an initial presentation
  3. Review the generated presentation in the preview panel

  ### Updating an Existing Presentation
  1. Enter your update notes in the **Update Notes** tab (feedback, changes, new content)
  2. Click **Update Presentation** to apply changes
  3. Review the updated presentation in the preview panel

  ## Files
  - `notes.md` — Source notes for the presentation content
  - `update_notes.md` — Notes describing changes to apply to an existing presentation
  - `presentation.html` — The generated presentation output
