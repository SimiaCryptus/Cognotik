Execution Configuration

Field Type Description
problem * String The challenge to approach with lateral thinking.
techniques List<String> reversal, random_stimulus, challenge_assumptions, exaggeration, escape, metaphor, provocation.
num_alternatives Int Ideas per technique (1-10, default: 5).
evaluate_feasibility Boolean Whether to perform a secondary evaluation pass.
domain_context String Optional domain or context to constrain the thinking.
constraints List<String> Additional constraints or requirements to consider.
input_files List<String> Glob patterns for context (e.g. **/*.kt).

Task Lifecycle

  1. Context Gathering: Reads specified input_files and prior execution state to ground the problem.
  2. Technique Application: Iterates through selected techniques, generating LateralIdea objects with novelty and feasibility scores.
  3. Synthesis: A specialized agent analyzes patterns across all techniques to find breakthrough "Recommended Approaches".
  4. Feasibility Pass: (Optional) Ranks ideas by practical implementation complexity and resource requirements.

Kotlin Boilerplate


val task = LateralThinkingTask(
    orchestrationConfig = config,
    planTask = LateralThinkingTaskExecutionConfigData(
        problem = "Optimize database query latency",
        techniques = listOf("exaggeration", "metaphor"),
        num_alternatives = 5
    )
)
orchestrator.run(task)
