Configuration Parameters

Field Type Description
game_title * String The title of the game used for context and file naming.
genre String Game genre (e.g., 'RPG', 'adventure', 'visual novel'). Default: 'RPG'.
narrative_style String 'linear', 'branching', or 'open-ended'. Default: 'branching'.
player_agency_level String 'low', 'medium', or 'high'. Affects choice impact. Default: 'high'.
num_main_characters Int Number of main characters (1-10). Default: 4.
num_branching_points Int Number of major branching points (3-15). Default: 8.
num_endings Int Number of possible endings (1-10). Default: 4.
player_role String 'protagonist', 'observer', or 'custom'. Default: 'protagonist'.
estimated_playtime_hours Int Estimated playtime (1-100). Affects word count. Default: 20.
include_dialogue_trees Boolean Whether to include detailed dialogue trees. Default: true.
include_character_arcs Boolean Whether to include character arc development. Default: true.
include_side_quests Boolean Whether to include side quest narratives. Default: true.
include_game_mechanics Boolean Whether to include game mechanics design. Default: true.
generate_character_portraits Boolean Triggers DALL-E/Midjourney asset generation.

Token Usage: High. This task performs multiple LLM passes and optional image generation.

Task Process Lifecycle

  • Initialization: Validates configuration and creates .game_narrative_design workspace.
  • Phase 1: Base Narrative: Executes NarrativeGenerationTask to establish core story beats.
  • Phase 2: Game Structure Analysis: Extracts characters, acts, and themes into a structured GameNarrative object.
  • Phase 2.5: Mechanics Design: (Optional) Designs core loops and systems that achieve ludonarrative harmony.
  • Asset Generation: (Optional) Triggers ImageProcessingAgent for character portraits.
  • Phase 3: Branching Map: Generates a comprehensive map of decision points and consequences.
  • Phase 4: Dialogue Trees: (Optional) Authors multi-turn branching conversations with emotional beats.
  • Phase 5: Multiple Endings: Defines unique resolutions and character fates for all narrative paths.
  • Phase 6: Side Quests: (Optional) Creates optional content that expands the world and character backstories.
  • Phase 7: Agency Analysis: Evaluates choice impact, replayability, and agency balance.
  • Phase 8: Final Design Document: Compiles all phases into a master Markdown document and JSON data file.

Kotlin Boilerplate


val task = GameNarrativeDesignTask(

    planTask = GameNarrativeDesignConfigData(
        game_title = "Project Orion",

        narrative_style = "branching",
        num_endings = 3,
        player_role = "protagonist",
        include_game_mechanics = true
    )
)
orchestrator.runTask(task)
