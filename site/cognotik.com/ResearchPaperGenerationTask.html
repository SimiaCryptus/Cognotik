Configuration Parameters

Field Type Default Description
research_topic * String - The main research question or topic to be explored.
paper_type String "empirical" Type of paper: empirical, theoretical, review, meta-analysis.
academic_level String "masters" Target level: undergraduate, masters, phd, postdoc.
target_word_count Int 8000 Total word count goal for the generated paper.
citation_style String "apa" Style: apa, mla, chicago, ieee.
include_literature_review Boolean true Whether to include a dedicated literature review section.
include_peer_review Boolean true Whether to simulate a critical academic peer review.
revision_passes Int 1 Number of self-editing passes (0-5).
research_files List<String> [] Specific source files to incorporate into the analysis.

Task Execution Lifecycle

  1. Research Analysis: Analyzes input context and research files to identify key themes and research gaps.
  2. Outline Generation: Creates a structured academic outline with section-specific word counts and purposes.
  3. Iterative Writing: Generates each section individually, maintaining context from previous sections and integrating citations.
  4. Bibliography Compilation: Aggregates all used citations into a formatted bibliography based on the selected style.
  5. Peer Review (Optional): Simulates a critical academic review to identify strengths and weaknesses.
  6. Final Assembly: Compiles the full Markdown document and provides a download link.

Embedded Execution (Kotlin)

Invoke this task programmatically using the UnifiedHarness in serverless mode.

import com.simiacryptus.cognotik.plan.TaskType
import com.simiacryptus.cognotik.plan.tools.writing.ResearchPaperGenerationTask.Companion.ResearchPaperGeneration
import com.simiacryptus.cognotik.plan.tools.writing.ResearchPaperGenerationTask.ResearchPaperGenerationTaskExecutionConfigData

fun generatePaper(harness: UnifiedHarness, projectDir: File) {
    val config = ResearchPaperGenerationTaskExecutionConfigData(
        research_topic = "The Role of AI in Modern DevOps",
        paper_type = "review",
        academic_level = "phd",
        target_word_count = 3000,
        include_peer_review = true
    )

    harness.runTask(
        taskType = ResearchPaperGeneration,
        typeConfig = null, // Use defaults
        executionConfig = config,
        workspace = projectDir,
        autoFix = true
    )
}
