Coding Mode

The Developer. An interactive, code-first environment where you can execute scripts, manipulate data, and orchestrate tasks directly via code.

Core Capabilities

Interactive REPL

Execute code snippets in real-time. Perfect for rapid prototyping, data analysis, and debugging complex logic.

Direct API Access

Interact directly with Cognotik's task orchestration engine and internal APIs through the scripting environment.

Multi-Language Support

Supports various runtime environments (like Groovy) to suit your scripting preference and project needs.

How It Works

1. Input & Context

You provide a natural language request or raw code. The system prepares a coding environment with access to project files, environment variables, and defined task tools.

2. Code Generation & Execution

The AI generates the necessary code to fulfill your request (or uses your provided code). This code is executed in a secure sandbox, capable of calling other agents or performing file I/O.

3. Result Visualization

Execution results are captured and displayed in tabbed views:

  • Code: The script that was run.
  • Output: Standard output (logs, print statements).
  • Result: The return value of the script.
