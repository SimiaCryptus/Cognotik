Cognotik Embedded

Integrate "Headless" AI agents directly into your software lifecycle. Automate refactoring, documentation, and testing within Gradle builds, CI/CD pipelines, or custom CLI tools.

View Documentation Quick Start

Key Capabilities

Headless Execution

Run agents without a UI. Perfect for background jobs, scripts, and server-side processing.

CI/CD Integration

Embed agents in GitHub Actions or Jenkins to perform code reviews or auto-fixes on every push.

Gradle Plugin

Wrap agent tasks in Gradle to automate boilerplate generation as part of your build process.

Unified Harness

A simple API to configure models, tools, and cognitive strategies programmatically.

🚀 Getting Started

Installation

Add the dependency to your build.gradle.kts:

kotlin 
dependencies {
    implementation("com.cognotik:webapp:2.0.39")
    implementation("org.slf4j:slf4j-simple:2.0.9")
}

Basic Usage

Initialize the UnifiedHarness in serverless mode:

kotlin 
val harness = UnifiedHarness(
    serverless = true,
    openBrowser = false,
    smartModel = OpenAIModels.GPT4o,
    modelInstanceFn = { /* Inject API Keys */ }
)
harness.start()

Running a Plan

Execute a high-level goal using a cognitive strategy:

kotlin 
harness.runPlan(
    prompt = "Refactor the database layer.",
    cognitiveSettings = CognitiveModeConfig(type = CognitiveModeType.Waterfall),
    workspace = File("./my-project"),
    autoFix = true
)

For detailed documentation on task configurations and advanced usage, refer to the Embedding Guide on GitHub.
