# How to Install a Plugin in Cognotic Desktop

## Overview

The Cognotic desktop application is extensible through plugins. This guide walks through the process of installing a plugin, accepting its license, and verifying any required subscriptions.

## Installing a Plugin

The Cognotic desktop application is extensible. You can install a plugin by clicking **Plugins** from the main page, then clicking **Upload Plugin**, followed by **Choose File**, and selecting the plugin JAR file.

You may want to check **Auto Load** and then click **Upload Plugin**.

## Accepting the License Agreement

Upon starting, the plugin asks you to accept the license agreement — click **OK** to proceed.

## Verifying Subscription Status

This plugin also requires you to be on Patreon and verify your subscription status. This plugin is for supporters of the Patreon. Once you click **Allow**, you can close that window.

## Using the Plugin

Refresh the home page and you will see some extra options that are covered in other demo videos.

## Summary

As you can see, plugin installation is simple and adds working applications to the Cognotic desktop.
