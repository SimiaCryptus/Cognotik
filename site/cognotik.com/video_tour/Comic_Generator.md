# Comic Generator App

## Introduction

Probably the most entertaining app is the Comic Serial app. It generates a series of comic books based on your prompts.

Here, let's say: **"Comic about food parakeets."**

## Setting Up Models

We saved this idea. Make sure that we have models selected. We will select **Gemini 3 Flash Preview** for the text model, and for the image model, let's use **Gemini 1 Flash Image Preview**. Save our model settings.

## How Comic Serial Works

The reason it's called "Comic Serial" is because you can generate a first comic book — which includes many frames — and then afterwards you can generate sequels. You can keep generating sequels as desired.

The final step is then to render the comic book into an HTML format, which uses the same images. It just gives it a nice HTML framing.

But first, we will monitor the generation of the comic book itself.

## Generation Process

### Script Creation

The system first produces a sketch of a script for the comic.

### Character Generation

The first step when generating comics is to generate character reference images. These are then used when rendering the comics themselves, in order to achieve artistic consistency.

### Page Generation

After characters are created, the system moves on to actual page generation. You can monitor this in real time.

## Results

The comic ends with even a nice little fourth-wall joke! Now that the generation has completed and my parakeets agree, it is time to render the comic book.

### Rendering

This renders the HTML structure that houses the comic. Since the basic comic book framing is somewhat basic, this should only take a moment.
