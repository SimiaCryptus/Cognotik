* This file records information specific to the Plugin Install demo.
* The `planscripts/` files contain the script for the demo, and are used to generate the video.

## Demo Summary

This demo covers the end-to-end process of installing a plugin in the Cognotic desktop application:

1. **Installing a Plugin** — Navigate to **Plugins** from the main page, click **Upload Plugin**, choose a plugin JAR file, optionally check **Auto Load**, and click **Upload Plugin**.
2. **Accepting the License Agreement** — On startup, the plugin prompts the user to accept a license agreement.
3. **Verifying Subscription Status** — Some plugins require Patreon subscription verification. The user clicks **Allow** and then closes the verification window.
4. **Using the Plugin** — After refreshing the home page, additional options provided by the plugin become available.

## Key Points

* Plugins are distributed as JAR files.
* The **Auto Load** option allows the plugin to load automatically on startup.
* Patreon-gated plugins require an OAuth-style subscription verification flow.
* Additional plugin functionality is covered in separate demo videos.
