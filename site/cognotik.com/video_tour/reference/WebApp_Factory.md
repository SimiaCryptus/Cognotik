# Web App Factory Demo

* This file records information specific to this demo.
* The `planscripts/` files contain the script for the demo, and are used to generate the video.

## Overview

The Web App Factory demo showcases the webapp-factory application, which transforms natural language descriptions into complete, runnable web applications. Users describe their idea, and the AI generates a full project with HTML, CSS, and JavaScript — ready to launch in the browser. This reference document ties together the demo plan script and the application documentation.

## References

- **Plan Script**: `../planscripts/WebApp_Factory.md` — Contains the step-by-step script used to produce the demo video.
- **Application README**: `../../../../desktop/src/main/resources/apps/webapp-factory/README.md` — Documents the webapp-factory application's features, architecture, and usage.

## Notes

* The demo plan script defines the sequence of actions and narration for the recorded demo.
* The webapp-factory app is located under the desktop module's resources at `apps/webapp-factory/`.
* The demo walks through building a graphing calculator as an example project, including running the build pipeline, viewing results, launching the app, and updating it with a dark theme via the updater.
