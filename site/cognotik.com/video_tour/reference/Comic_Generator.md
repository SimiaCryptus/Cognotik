# Comic Generator - Demo Reference

* This file records information specific to this demo.
* The `planscripts/` files contain the script for the demo, and are used to generate the video.

## Overview

The Comic Generator is a demo application that showcases AI-powered comic serial generation. It is located in the desktop application resources under `apps/comic-serial/`.

## Application Location

- **App Path:** `desktop/src/main/resources/apps/comic-serial/`
- **Plan Script:** `planscripts/Comic_Generator.md`

## Demo Details

The Comic Generator demo illustrates the process of creating serialized comic content using the SimiaCryptus AI platform. The plan script defines the sequence of actions and narration used to produce the demo video.
