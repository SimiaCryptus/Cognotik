# Comic Generator Demo Script

## Introduction

**Narration:**
> Probably the most entertaining app is the Comic Serial app. It generates a series of comic books based on your prompt.

**Action:** Open the Comic Serial application from the app list.

---

## Step 1: Enter a Prompt

**Narration:**
> Let's start by entering a prompt. We'll go with: "Make a comic about rude parakeets that will not stop talking."

**Action:** Click into the prompt field and type: `Make a comic about rude parakeets that will not stop talking.`

---

## Step 2: Configure Model Settings

**Narration:**
> Before we generate, let's make sure we have the right models selected. For the text model, we'll select Gemini Flash 2.0 — it defaults to the first on the list, so we need to change it. Select Gemini 2.0 Flash. For the image model, let's use Gemini 2.0 Flash image generation preview.

**Action:**
1. Open the model settings panel.
2. Set the text model to **Gemini 2.0 Flash**.
3. Set the image model to **Gemini 2.0 Flash Image Generation Preview**.
4. Click **Save** to confirm the model settings.

---

## Step 3: Generate the First Comic Book

**Narration:**
> The reason it's called Comic Serial is because you can generate a first comic book — which includes many frames — and then afterwards you can generate sequels. You can keep generating sequels as many times as you like. But first, let's generate our initial comic book.

**Action:** Click the **Generate** button to start comic book generation.

---

## Step 4: Monitor Script Generation

**Narration:**
> You can monitor the generation in real time. First, it sketches out a script for the comic.

**Action:** Observe the output panel as the script/outline is generated.

---

## Step 5: Character Reference Generation

**Narration:**
> The first step in generating the comic is to create character reference images. These reference images are then used when rendering the comic panels themselves, in order to achieve visual consistency across frames.

**Action:** Watch as character reference images are generated and displayed.

---

## Step 6: Page Generation

**Narration:**
> Now we're on to the actual page generation. Again, you can monitor this in real time as each panel is created. It even ends with a nice little fourth-wall joke.

**Action:** Observe as comic pages and panels are generated one by one.

---

## Step 7: Render the Comic Book

**Narration:**
> Great — now that the generation has completed, it's time to render the comic book into HTML format. This uses the same images but gives them a nice HTML framing for a more attractive presentation. Since the basic comic book framing is fairly straightforward, this should only take a moment.

**Action:** Click the **Render** button to generate the HTML output.

---

## Step 8: Preview the Comic Book

**Narration:**
> Here we go. Let's open this in a new tab and preview it. We've got our character reference images at the top, and now a much more attractive presentation with the comic panels and textual dialogue alongside each frame.

**Action:**
1. Click the link or button to open the rendered HTML in a new browser tab.
2. Scroll through the comic book, showing character references and comic panels with dialogue.

---

## Closing

**Narration:**
> And that is the Comic Book Generator. I hope you enjoy it!

**Action:** Return to the application main screen.
