# Cognotic Desktop — Windows Installation Demo Script

## Introduction

> **Narration:**
> Welcome to this demo video on how to install Cognotic Desktop on Windows.

**Action:** Show the desktop or title screen.

---

## Step 1: Download the Installer

> **Narration:**
> First, go to [cognotic.com](https://cognotic.com) and download the installer file. You can also find all installer artifacts on GitHub under Releases.

**Action:** Open a browser and navigate to `cognotic.com`. Highlight the download button. Briefly show the GitHub Releases page as an alternative.

> **Narration:**
> Click "Download for Windows" and save the file.

**Action:** Click the Windows download link. Save the file when prompted.

---

## Step 2: Install the Application

> **Narration:**
> Because this isn't a commonly downloaded file, Windows SmartScreen may flag it. You may need to click "Keep" or "More info → Run anyway" to proceed.

**Action:** Show the SmartScreen warning and demonstrate how to manually keep the file.

> **Narration:**
> Once you've kept the file, open it and install it like any standard desktop application.

**Action:** Run the installer and step through the installation wizard to completion.

---

## Step 3: Launch Cognotic

> **Narration:**
> Now we need to configure the application. Open the Start menu and launch Cognotic.

**Action:** Open the Start menu, search for "Cognotic," and click to launch it.

> **Narration:**
> Cognotic is a server-based application. When you launch it from the Start menu, it starts a local server in the background. To open the web interface, go to the taskbar, find the Cognotic server icon, and click it. This will open a browser page.

**Action:** Locate the Cognotic icon in the system tray / taskbar. Click it to open the browser-based UI.

---

## Step 4: Register a Local Login

> **Narration:**
> You'll be presented with a login screen. This is a system-local login used to secure your API credentials. If you don't have an account yet, you can easily register one.

**Action:** Show the login page. Click the registration option.

> **Narration:**
> Enter a username and password. Note that spaces are not allowed in the password. Weak passwords are permitted but not recommended.

**Action:** Enter a username and password in the registration form and submit.

> **Narration:**
> After registering, a confirmation dialogue will appear. This is a security measure to prevent someone over the network from creating accounts on your local server. Note: this dialogue sometimes appears behind other windows, so you may need to use Alt+Tab to find it. Click "Yes" to confirm.

**Action:** Show the confirmation dialogue (use Alt+Tab if necessary to bring it to the foreground). Click "Yes."

---

## Step 5: Add an API Key

> **Narration:**
> Now that you're logged in, go to Settings to add your API key. Cognotic supports a number of providers, but I primarily recommend Anthropic and Gemini.

**Action:** Navigate to the Settings page. Show the provider selection dropdown.

> **Narration:**
> Select your provider, paste in your API key, and save.

**Action:** Select "Anthropic" as the provider. Paste an API key into the field and click Save.

---

## Step 6: Test the Installation

> **Narration:**
> After saving your API key, refresh the page. Then open a basic chat to verify everything is working. You should see available models — for example, Haiku from Anthropic — which confirms that the models were discovered successfully.

**Action:** Refresh the browser page. Open the chat interface and show the model list.

> **Narration:**
> Let's send a quick test message to confirm full functionality.

**Action:** Type "Hi" into the chat and send. Wait for a response.

> **Narration:**
> And there we go. Cognotic Desktop is now fully installed, configured, and tested on Windows. You're ready to start using the applications.

**Action:** Show the successful response. Pause briefly on the completed chat.
