# Plugin Install — Demo Script

## Introduction

**Narration:**
> The Cognotic desktop application is extensible — you can add new functionality by installing plugins. In this demo,
> we'll walk through the full process of installing a plugin, accepting its license agreement, verifying a subscription,
> and seeing the new features it adds.

**Action:** Start on the Cognotic desktop application main page.

---

## Step 1: Navigate to the Plugins Page

**Narration:**
> From the main page, click **Plugins** to open the plugin management screen.

**Action:** Click the **Plugins** button on the main page.

---

## Step 2: Upload the Plugin

**Narration:**
> Click **Upload Plugin**, then **Choose File**, and select the plugin JAR file you'd like to install.

**Action:**

1. Click **Upload Plugin**.
2. Click **Choose File** in the file picker dialog.
3. Select the plugin `.jar` file from the filesystem.

---

## Step 3: Configure and Confirm Upload

**Narration:**
> Before uploading, you may want to check **Auto Load** so the plugin loads automatically on startup. Then click *
*Upload Plugin** to complete the installation.

**Action:**

1. Check the **Auto Load** checkbox.
2. Click **Upload Plugin**.

---

## Step 4: Accept the License Agreement

**Narration:**
> When the plugin starts for the first time, it will prompt you to accept a license agreement. Click **OK** to accept
> and continue.

**Action:** In the license agreement dialog, click **OK**.

---

## Step 5: Verify Subscription Status (Patreon)

**Narration:**
> This particular plugin is available to supporters of my Patreon. It requires you to verify your subscription status.
> Click **Allow** to authorize the verification.

**Action:**

1. In the Patreon verification prompt, click **Allow**.
2. Close the verification window once complete.

---

## Step 6: See the New Plugin Features

**Narration:**
> Now, refresh the home page. You'll see additional options provided by the newly installed plugin. As you can see,
> plugin installation is simple and immediately adds working functionality to the application.

**Action:**

1. Close any remaining dialogs.
2. Navigate back to the home page and refresh.
3. Briefly highlight the new options that have appeared.

---

## Key Points to Emphasize

- Plugins are distributed as **JAR files**.
- The **Auto Load** option allows the plugin to load automatically on startup.
- Some plugins are gated behind a **Patreon subscription** and require an OAuth-style verification flow.
- Additional plugin functionality is covered in separate demo videos.
