# Web App Factory Demo Script

## Introduction

> **Narration:**
> "To generate a web application, you can use the Web App Factory. Simply enter some details about what you want to
> build."

**Action:** Open the Web App Factory application. Navigate to the idea input area.

---

## Step 1: Describe Your Idea

> **Narration:**
> "For this demo, we'll implement a graphing calculator. Type your idea — 'Implements a graphing calculator' — and save
> it."

**Action:** Type `Implements a graphing calculator` into the idea input field. Click **Save**.

---

## Step 2: Select Models

> **Narration:**
> "Make sure you have your models selected. We're going to be using Gemini Flash Preview for this demo. You also need to
> have an image model selected, even if you aren't using one — it doesn't have to be an actual image model, you just need
> to select something."

**Action:** Confirm that the text model is set to **Gemini Flash Preview**. Select any available model in the image
model slot.

---

## Step 3: Run the Build Pipeline

> **Narration:**
> "Now we go to the pipeline and click Build Web App. This is the only step in the pipeline, but it's quite involved. It
> starts by generating a project plan of tasks and then executes them, respecting all of their dependencies."

**Action:** Navigate to the **Pipeline** tab. Click **Build Web App**. Wait for the project plan to generate.

---

## Step 4: Review the Project Plan

> **Narration:**
> "Here we see the project plan with five different tasks. We can view the tasks themselves in the task list. First, it
> creates the foundational documents for the project — the HTML structure and visual style. Then it implements the core
> logic. Once complete, the web app UI will update."

**Action:** Observe the generated project plan. Scroll through the task list to show each task: foundational documents,
HTML structure, visual styling, and core logic implementation. Wait for all tasks to complete.

---

## Step 5: View the Results

> **Narration:**
> "The implementation step is done. We can see the README in the project root. At this point, we can download the
> project as a zip if we want."

**Action:** Click on the project root to show the generated **README** file. Point out the **Download Zip** option.

---

## Step 6: Git Integration

> **Narration:**
> "Also notable is that this application has Git support integrated. If you're not familiar, Git is a version control
> system that tracks changes to your files. The generated files have been saved to Git automatically."

**Action:** Show the Git integration panel or status indicator confirming that files have been committed.

---

## Step 7: Launch the App

> **Narration:**
> "Now that the implementation is done, we can launch the app. Here we see it plotting sine of x."

**Action:** Click **Launch App**. The graphing calculator opens in the browser, displaying a plot of `sin(x)`.

---

## Step 8: Test the Calculator

> **Narration:**
> "Let's try some different expressions. What about sine of x plus ten of x? That looks about right. Or divide instead
> of times? What about to the power? That looks interesting. The calculator seems to work well."

**Action:**

1. Change the expression to `sin(x) + 10*x` — observe the updated plot.
2. Modify the expression to use division — observe the result.
3. Try an exponentiation expression — observe the result.

---

## Step 9: Request an Update

> **Narration:**
> "It works, but it's too bright. Let's ask for some changes. We can update our web app using the updater. We'll say: '
> Implement a dark theme and a theme toggle.'"

**Action:** Navigate to the **Update** section. Type `Implement a dark theme and a theme toggle` into the update input
field. Click **Save**.

---

## Step 10: Run the Update

> **Narration:**
> "Save our notes and run the update. This will update the project with our requested changes. This is also useful if
> you find bugs, want to add a feature, or really need any change at all."

**Action:** Click **Run Update**. Wait for the update pipeline to complete.

---

## Step 11: Verify the Update

> **Narration:**
> "The update is done. Let's go back to our graphing calculator and refresh it. And look — we've got a theme button, and
> it works!"

**Action:** Switch to the browser tab with the graphing calculator. **Refresh** the page. Click the **Theme Toggle**
button to switch to dark mode. Demonstrate toggling back and forth.

---

## Step 12: Review Usage and Cost

> **Narration:**
> "So that's how to use the Web App Factory to generate your own applications. We can also check usage — this entire
> demo cost about eleven cents."

**Action:** Navigate to the **Usage** panel. Show the total cost of approximately **$0.11**.

---

## Closing

> **Narration:**
> "I hope you find this useful."

**Action:** End the recording.
