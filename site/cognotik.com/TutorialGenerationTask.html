Field Type Description
goal * String The final outcome the user should achieve (e.g., 'deploy a web app').
target_platform String Environment context (Windows, Linux, Docker, etc.). Default: "cross-platform".
skill_level String Target audience level: beginner, intermediate, advanced.
verbosity String Level of detail: concise, detailed, verbose.
target_step_count Int Number of main steps (3 to 20). Default: 7.
include_troubleshooting Boolean Whether to generate a common errors section.
input_files List<String> Optional glob patterns for source code context.
Phase 1: Planning
Generates a TutorialOutline including prerequisites, learning objectives, and step-by-step purpose mapping.
Phase 2: Writing
Iteratively writes each TutorialStep, injecting code blocks, validation logic, and platform-specific commands.
Phase 3: Hardening
Compiles TroubleshootingSection and NextSteps to ensure the user isn't left at a dead end.
