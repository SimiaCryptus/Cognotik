Parallel Mode

The Factory. Scale your cognitive workflows by executing tasks concurrently across multiple inputs. Ideal for batch processing, codebase refactoring, and parameter sweeps.

Key Capabilities

Interactive Planning

Review and revise the execution plan, including variable expansions and task combinations, before processing begins.

Concurrency Control

Manage resource usage with a fixed concurrency processor to maximize throughput without overloading the system.

Dynamic Expansion

Automatically expand file patterns (globs) into lists of target files for processing.

How It Works

1. Intent Analysis & Planning

The system parses your request into a ParallelPlan. It identifies variables (lists or file globs) and a template. An interactive review step allows you to verify the expanded file lists and generated task combinations before execution.

2. Expansion & Combination

Variables are expanded (e.g., globs like src/*.kt are resolved to file paths). The system then generates task combinations:

  • CrossJoin: Executes the template for every possible combination of variables.
  • Zip: Pairs variables by index (1st item with 1st item, etc.).
3. Concurrent Execution

A FixedConcurrencyProcessor executes tasks in parallel. Each thread runs an isolated session where the template is rendered and dynamically routed to the appropriate agent (e.g., Coding, Shell). A Tabbed Display organizes these streams, allowing real-time monitoring of individual task outputs.

Example Configuration


{
  "variables": {
    "file": ["src/User.kt", "src/Session.kt"],
    "aspect": ["Security", "Performance"]
  },
  "template": "Review {{file}} focusing on {{aspect}} issues.",
  "concurrency": 4,
  "mode": "CrossJoin",
}

This configuration generates 4 tasks (2 files × 2 aspects) running in parallel, managed via a tabbed interface.
