Parallel Mode

The Factory. Scale your cognitive workflows by executing tasks concurrently across multiple inputs. Ideal for batch processing, codebase refactoring, and parameter sweeps.

Key Capabilities

Batch Processing

Define a task template and apply it to a list of variables, such as files or data points.

Concurrency Control

Manage resource usage with configurable thread pools to maximize throughput without overloading the system.

Dynamic Expansion

Automatically expand file patterns (globs) into lists of target files for processing.

How It Works

1. Configuration

The user provides a natural language request that implies batch processing. The system parses this into a ParallelPlan containing:

  • Variables: Lists of items (e.g., files matching src/*.kt).
  • Template: A prompt string with placeholders (e.g., "Analyze {{file}}").
  • Mode: Combination strategy (CrossJoin or Zip).
2. Expansion & Combination

Variables are expanded (e.g., globs resolved to file paths). The system then generates task combinations:

  • CrossJoin: Executes the template for every possible combination of variables.
  • Zip: Pairs variables by index (1st item with 1st item, etc.).
3. Execution

A FixedConcurrencyProcessor executes the generated tasks in parallel. Each task is treated as an independent session, allowing for isolated context and error handling.

Example Configuration


{
  "variables": {
    "file": ["User.kt", "Session.kt", "Auth.kt"],
    "check": ["Security", "Performance"]
  },
  "template": "Review {{file}} focusing on {{check}} issues.",
  "mode": "CrossJoin",
  "concurrency": 4
}

This configuration would generate 6 tasks (3 files × 2 checks) running in parallel.
