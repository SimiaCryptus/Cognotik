Configuration Parameters

Field Type Description
questions * List<SurveyQuestion> List of survey questions to ask respondents. Supports Multiple Choice, Likert, Open-Ended, etc.
respondent_profiles * List<RespondentProfile> Templates defining demographics and characteristics for simulated personas.
respondents_per_profile Int Number of simulated respondents per profile. Default: 10.
cross_tabulation Boolean Generate analysis across demographic dimensions. Default: true.
bias_detection Boolean Detect response patterns like central tendency or primacy effects. Default: true.
sentiment_analysis Boolean Perform LLM-based sentiment analysis on open-ended responses. Default: true.
temperature Double Controls variance in persona responses (0.0 to 1.0). Default: 0.7.

Task Lifecycle

  1. Persona Generation: Creates unique SimulatedRespondent instances based on profiles and demographic variations.
  2. Survey Execution: Parallelized LLM calls where each persona answers the question set based on their background.
  3. Statistical Analysis: Computes frequency distributions, means, and standard deviations.
  4. Advanced Analytics: Performs sentiment analysis on text and cross-tabs on demographics.
  5. Reporting: Generates a multi-tabbed UI and a persistent Markdown/HTML report.

Embedded Execution (Headless)

Use the UnifiedHarness to run this task programmatically in CI/CD or automated research pipelines. 


import com.simiacryptus.cognotik.plan.tools.social.LLMPollSimulationTask
import com.simiacryptus.cognotik.plan.tools.social.LLMPollSimulationTask.*
import com.simiacryptus.cognotik.plan.tools.TaskTypeConfig
import java.io.File

harness.runTask(
    taskType = LLMPollSimulationTask.LLMPollSimulation,
    typeConfig = TaskTypeConfig(), // Static tool settings
    executionConfig = LLMPollSimulationTaskExecutionConfigData(
        questions = listOf(
            SurveyQuestion(id = "q1", text = "Do you prefer Kotlin over Java?", type = QuestionType.YES_NO)
        ),
        respondent_profiles = listOf(
            RespondentProfile(description = "Backend Engineer", demographics = mapOf("role" to "Dev"))
        ),
        respondents_per_profile = 25,
        bias_detection = true
    ),
    workspace = File("./poll-results"),
    autoFix = true
)
