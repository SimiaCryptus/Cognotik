The Power of Recursion

The SubPlanningTask is the framework's most powerful tool for "divide and conquer" strategies. It allows a plan to spawn independent instances of the orchestrator.

  • Custom Context: Sub-plans can use different Cognitive Modes than their parents.
  • Context Passing: Relevant results from parent tasks are automatically injected as context.
  • Result Aggregation: Once complete, the sub-plan returns a concise summary to the main workflow. 
val subTask = SubPlanningTask(
    goal = "Design database schema",
    mode = CognitiveMode.AdaptivePlanningMode,
    enabledTasks = setOf(TaskType.AnalysisTask, TaskType.RunCodeTask)
)
