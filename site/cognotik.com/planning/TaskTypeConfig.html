Configuration Parameters

Field Type Description
task_type * String The unique ID used by PlanTaskTypeIdResolver to instantiate the correct subclass.
name String Optional display name. Defaults to task_type if not provided.
model ApiChatModel Optional model override. Allows specific tasks to use different LLMs (e.g., GPT-4 for logic, GPT-3.5 for summaries).

Embedded Invocation

To invoke a task using TaskTypeConfig in an embedded environment:


val harness = UnifiedHarness(serverless = true, ...)
harness.start()

// 1. Define the Type Configuration
val typeConfig = TaskTypeConfig(
    task_type = "FileModificationTask",
    model = OpenAIModels.GPT4o.asApiChatModel()
)

// 2. Define Runtime Execution Data
val executionConfig = FileModificationTaskExecutionConfigData(
    files = listOf("src/Main.kt"),
    modifications = "Add error handling to the main loop"
)

// 3. Execute
harness.runTask(
    taskType = TaskType.FileModificationTask,
    typeConfig = typeConfig,
    executionConfig = executionConfig,
    workspace = File("./my-project")
)
