Runtime Configuration

Field Type Description
inquiry_goal String The high-level purpose of the analysis. *
inquiry_questions List<String> Specific questions to be addressed. *
input_files List<String> Glob patterns (e.g., **/*.kt) to include as context.

* Either inquiry_goal or inquiry_questions must be provided.

Task Lifecycle

  1. Context Resolution: Scans the workspace using provided glob patterns, filtering out ignored files.
  2. Content Extraction: Reads text files directly; uses PaginatedDocumentReader for complex formats (PDF, DocX).
  3. LLM Synthesis: Feeds the gathered context into a specialized "Insight" agent.
  4. Interactive Output: Renders a tabbed UI in the session, allowing the user to ask follow-up questions.

Type Configuration
