Waterfall Mode

The Architect. A deliberate, plan-first approach that analyzes requirements, designs a comprehensive strategy, and executes with precision.

Core Capabilities

Strategic Planning

Generates a full dependency graph of tasks before execution begins, ensuring all prerequisites are identified.

Human-in-the-Loop

Presents the plan for review. You can modify the strategy or approve it, preventing wasted effort on wrong paths.

Transparent Reporting

Produces detailed transcripts and saves the execution plan as JSON for reproducibility or future reference.

How It Works

1. Analysis & Design

When you provide a goal, Waterfall Mode first scans the available context (files, tools). It then uses a planning agent to decompose the goal into a set of discrete tasks (e.g., WriteFileTask, RunCodeTask).

2. Visualization & Review

The proposed plan is rendered in multiple formats:

  • Text: A readable summary of steps.
  • JSON: The raw data structure.
  • Diagram: A Mermaid graph showing dependencies.
The system pauses here (unless autoFix is enabled) to allow you to discuss and refine the plan.

3. Orchestration

Once approved, the TaskOrchestrator takes over. It executes tasks in the correct order based on dependencies. Outputs from one task can be fed into subsequent tasks.
