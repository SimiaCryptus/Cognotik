Extension Functions

Function Receiver Description
truncateForDisplay(maxLength) String Truncates text and appends a count of omitted characters. Default 10,000.
safeComplete(message, log) SessionTask Attempts to complete the task with Markdown rendering; catches and logs exceptions to prevent crash loops.
tripleLog(e, log, transcript, context) SessionTask Logs to UI (error), SLF4J (error), and Transcript (Markdown with stack trace).
toApiChatModel() ChatModel Resolves API keys and base URLs from UserSettings. Throws IllegalArgumentException if key is missing.

Lifecycle & Logic

Model Resolution: toApiChatModel performs a lookup against ApplicationServices.fileApplicationServices(). It retrieves the UserSettings and finds the matching ApiData for the model's provider. It calls .validate() on the data before returning the resolved ApiChatModel.

Safe Completion: safeComplete wraps the standard complete(message) call in a try-catch block. It first attempts to render the message as Markdown. If an exception occurs (e.g., session already closed or rendering error), it logs a warning and falls back to raw text, ensuring the UI spinner is cleared.

Triple Log Rule: This utility enforces consistent error reporting across three layers: the User Interface (via task.error()), the System Logs (via SLF4J), and the persistent Task Transcript (as a Markdown entry with a collapsible stack trace).

Display Optimization: truncateForDisplay ensures that massive log outputs or LLM responses do not crash the browser UI by enforcing a default 10,000 character limit while preserving the start of the content.

Embedded Execution

When using Cognotik as an embedded engine (Headless mode), TaskUtils functions are critical for handling model resolution without a UI.


import com.simiacryptus.cognotik.apps.general.UnifiedHarness
import com.simiacryptus.cognotik.chat.model.OpenAIModels

val harness = UnifiedHarness(
    serverless = true,
    openBrowser = false,
    smartModel = OpenAIModels.GPT4o,
    modelInstanceFn = { apiChatModel ->
        // TaskUtils logic is used internally here to resolve keys
        val apiKey = System.getenv("OPENAI_API_KEY")
        apiChatModel.model!!.instance(key = apiKey)
    }
)

harness.start()

Custom Task Implementation


import com.simiacryptus.cognotik.plan.tools.safeComplete
import com.simiacryptus.cognotik.plan.tools.tripleLog
override fun run() {
    try {
        val result = doWork()
        this.safeComplete(result, logger)
    } catch (e: Exception) {
        this.tripleLog(e, logger, transcript, "Work failed")
    }
}
