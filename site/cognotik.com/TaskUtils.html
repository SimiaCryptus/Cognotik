TaskUtils

Core extension functions for task lifecycle management, safe completion, and model resolution.

Category: Utility Side-Effect Safe Internal API
⚙️ Kotlin Implementation

// Truncate large logs for UI
val displayLog = rawOutput.truncateForDisplay(10000)

// Safe completion with logging
task.safeComplete("Operation finished", logger)

// Resolve API credentials
val apiModel = chatModel.toApiChatModel() // Resolves keys
→
👁️ Runtime Behavior
// truncateForDisplay output:
[2023-10-27 10:00:00] INFO: Starting...
... (truncated for display, 4200 characters omitted)
// safeComplete log (on failure):
[WARN] Error completing task: Connection reset
// toApiChatModel result:
ApiChatModel(model=GPT-4, provider=OpenAI, key="sk-...", baseUrl="https://api.openai.com/v1")

Extension Functions

Function Receiver Description
truncateForDisplay(maxLength) String Truncates text and appends a count of omitted characters. Default 10,000.
safeComplete(message, log) SessionTask Attempts to complete the task; catches and logs exceptions to prevent crash loops.
toApiChatModel() ChatModel Resolves API keys and base URLs from UserSettings. Throws IllegalArgumentException if key is missing.

Lifecycle & Logic

Model Resolution: toApiChatModel performs a lookup against ApplicationServices.fileApplicationServices(). It retrieves the UserSettings and finds the matching ApiData for the model's provider. It calls .validate() on the data before returning the resolved ApiChatModel.

Safe Completion: safeComplete wraps the standard complete(message) call in a try-catch block. If an exception occurs (e.g., session already closed), it logs a warning instead of propagating the error, preventing crash loops in task finalization logic.

Display Optimization: truncateForDisplay ensures that massive log outputs or LLM responses do not crash the browser UI by enforcing a default 10,000 character limit while preserving the start of the content.

Boilerplate


import com.simiacryptus.cognotik.plan.tools.safeComplete
import com.simiacryptus.cognotik.plan.tools.truncateForDisplay

class MyCustomTask : SessionTask() {
    override fun run() {
        try {
            val result = performWork()
            this.safeComplete(result.truncateForDisplay(), logger)
        } catch (e: Exception) {
            this.safeComplete("Failed: ${e.message}", logger)
        }
    }
}
