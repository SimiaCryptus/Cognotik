AbstractFileTask

The foundational base class for all file-centric tasks. Provides robust glob-based file resolution, automated content extraction for non-text formats, and intelligent binary file filtering.

Execution Configuration

Field Type Description
files * List<String> Relative paths or glob patterns (e.g. **/*.js) for output/target files.
related_files List<String> Additional context files. Supports glob patterns.
extractContent Boolean If true, uses PaginatedDocumentReader to pull text from PDFs, HTML, etc. Defaults to false.

Automatic Filtering

The task automatically ignores binary and media files unless content extraction is explicitly enabled. Ignored extensions include:

.class, .jar, .exe, .png, .jpg, .mp4, .zip, .dll

Task Lifecycle

  1. Pattern Resolution: Resolves files and related_files using the system's default PathMatcher (glob).
  2. Filtering: Removes files matching the isIgnored() criteria (binaries/media) and .llmignore rules.
  3. Content Loading:
    • Text files are read directly.
    • If extractContent is active, non-text files are processed via getDocumentReader().
  4. Context Assembly: Files are wrapped in Markdown blocks with relative path headers for LLM consumption.

Embedded Invocation

To use tasks derived from AbstractFileTask in an automated pipeline, use the UnifiedHarness.


import com.simiacryptus.cognotik.apps.general.UnifiedHarness
import com.simiacryptus.cognotik.plan.TaskType
import com.simiacryptus.cognotik.plan.tools.file.FileModificationTaskExecutionConfigData

val harness = UnifiedHarness(serverless = true).apply { start() }

// Example: Running a FileModificationTask (which extends AbstractFileTask)
harness.runTask(
    taskType = TaskType.FileModificationTask,
    typeConfig = FileModificationTaskTypeConfig(name = "AutoRefactor"),
    executionConfig = FileModificationTaskExecutionConfigData(
        files = listOf("src/**/*.kt"),
        related_files = listOf("docs/architecture.md"),
        extractContent = true,
        modifications = "Update copyright headers to 2024"
    ),
    workspace = File("./my-project"),
    autoFix = true
)

Test Case Example

For unit testing your own tasks, you can mock the OrchestrationConfig and provide a local filesystem root:


val config = OrchestrationConfig(
    sessionId = "test-session",
    workingDir = tempDir.absolutePath
)
val task = MyFileTask(config, MyExecutionConfig(files = listOf("test.txt")))
task.run()
