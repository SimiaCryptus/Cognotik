SoftwareDesignDocumentTask

Generates comprehensive software design documentation including Mermaid diagrams, requirements specifications, architectural blueprints, and structured project planning data (JSON) for immediate execution.

Field Type Description
project_name* String The name/title of the software project.
system_description* String High-level description of the software system to design.
generate_architecture Boolean Generate C4, component, and deployment diagrams. Default: true.
generate_project_data Boolean Output project data JSON with tasks, epics, and sprints. Default: true.
sprint_count Int Number of sprints to plan. Default: 6.
input_files List<String> Glob patterns for source files to use as context.

Task Lifecycle

  1. Context Gathering: Scans input_files and prior task outputs to build a knowledge base.
  2. Iterative Generation: Sequentially generates Use Cases, Requirements, Architecture, and Data Models.
  3. Diagram Rendering: Converts structural logic into Mermaid syntax for visual display.
  4. Project Synthesis: Maps requirements to Epics and Tasks, distributing them across Sprints.
  5. Artifact Export: Produces a downloadable project_data.json and a full Markdown report.
// Kotlin Orchestration Example
val designTask = SoftwareDesignDocumentTask(
    orchestrationConfig = config,
    planTask = SoftwareDesignDocumentTaskExecutionConfigData(
        project_name = "MyProject",
        system_description = "A cloud-native CRM",
        generate_test_plan = true
    )
)
orchestrator.run(designTask)
