Architectural Patterns

Mode Name Architecture Best Use Case
WaterfallMode Plan -> Review -> Execute Well-defined problems requiring roadmap approval.
ConversationalMode Listen -> Act -> Reply Interactive debugging or simple "Chat with Code".
AdaptivePlanningMode Loop(Think -> Act -> Reflect) Complex goals requiring research and self-correction.
PersonaChatMode Persona -> Expand -> Execute High-level orchestration with complex state management.

Expansion Syntax

PersonaChatMode supports powerful meta-programming syntax to trigger multiple tasks or parallel executions.

Syntax Name Description
@[A|B] Alternatives Executes the prompt once for each option in parallel.
@{A -> B} Sequence Executes steps in order, passing context forward.
@(1..5) Range Iterates through a numeric range.
@Topic Topic Ref Injects aggregated entities from the conversation history.

Cognitive Schema Strategies

Strategies define the "Persona" and internal state structure, separating control flow from reasoning style.

Strategy Reasoning Style Internal State
Project Manager Generalist Tracks short-term vs. long-term goals.
Scientific Method Debugger Formulates hypotheses and tracks established facts.
Agile Developer Coder Follows TDD loops: Fail -> Implement -> Refactor.
Critical Auditor Security Adversarial mindset designed to find flaws.

Implementation Skeleton


// PersonaChatMode execution loop logic
val strategy = config.cognitiveStrategy
var state = strategy.initialize(userPrompt, ...)

while (!state.isComplete()) {
    // 1. Get Guidance from Persona
    val guidance = strategy.getTaskSelectionGuidance(state)

    // 2. Select & Execute Task
    val result = taskChooser.select(guidance).execute()

    // 3. Update Persona State (Reflection)
    state = strategy.update(state, result, ...)
    
    // 4. Render to Tabbed UI
    task.tabs["State"].update(strategy.formatState(state))
}
