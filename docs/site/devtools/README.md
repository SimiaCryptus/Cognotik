# Dev Tools

*Doc-op driven pipelines and utilities for researching, building, reviewing, and scaffolding code.*

- [Builder](./builder.md) — A doc-op pipeline that researches an unfamiliar repo and turns the answer into an executable `build.sh`.
- [Code Research](./coder.md) — Research → summarize → follow-up → execute pipeline over a codebase.
- [Greenfield Implementer](./greenfield.md) — Take a one-paragraph product idea and walk it all the way to a working, tested, documented project skeleton.
- [Reviewer](./reviewer.md) — Schema-driven code review pipeline that turns AI findings into runnable follow-up tasks.
