# Modules

*An index of Cognotik's modules — the building blocks you compose to build AI-powered applications, tools, and integrations.*

- [CLI](./cli.md) — A minimal, dependency-light command-line front end for driving documentation generation from your terminal.
- [Core](./core.md) — The foundation layer for building AI-powered applications on the JVM.
- [Desktop](./desktop.md) — Ship Cognotik as a native, installable application — no browser tab, no terminal required.
- [DocOps](./docops.md) — Turn markdown specs into planned, scheduled, executed code changes.
- [Experiment](./experiment.md) — A JVM-native sandbox for document processing, browser automation, and scripting experiments.
- [Groovy](./groovy.md) — Script your AI workflows with dynamic, JVM-native Groovy support.
- [IntelliJ Plugin](./intellij.md) — Bring Cognotik's agentic AI coding assistant directly into your IntelliJ-based IDE.
- [Kotlin Runtime](./kotlin.md) — Compile, execute, and sandbox Kotlin scripts on the fly — as a first-class scripting engine for Cognotik agents.
- [Cognotik Core (lwcore)](./lwcore.md) — The foundation layer for building AI-powered JVM applications — model actors, session state, storage, and patching, all in one library.
- [Providers](./providers.md) — The connective tissue between Cognotik and the AI models, storage backends, and platform services that power it.
- [Scala](./scala.md) — First-class Scala language support for Cognotik's JVM-based AI coding platform.
- [Standard Tools](./stdtools.md) — A batteries-included toolkit of production-ready agent capabilities — document processing, browser automation, code generation, and more.
- [Tasklib](./tasklib.md) — Turn a single high-level goal into a coordinated, dependency-aware set of AI-executed development tasks.
- [Cognotik Core (text)](./text.md) — Turn free-form LLM output into safe, validated file changes — deterministically.
- [Tool](./tool.md) — Bring AI-powered code review, auto-fixing, and issue resolution directly into your CI/CD pipeline.
- [webapp-v2](./webapp-v2.md) — A dependency-light, framework-free chat UI that streams live HTML from your Cognotik server straight into the browser.
- [Webui](./webui.md) — Build interactive, AI-powered web applications with real-time chat, task orchestration, and rich diff tooling — in pure JVM.
