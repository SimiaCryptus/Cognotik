# Cognitive Modes

Cognitive modes define how Cognotik reasons about and executes your request — pick the one that matches how well-defined your task is.

- [Adaptive Planning Mode](./AdaptivePlanning.md) — Best for open-ended or exploratory problems where you don't know the full plan up front, since it figures out what to do next based on what's already happened rather than committing to a rigid upfront plan.
- [Conversational Mode](./Conversational.md) — Best for ongoing, chat-style collaboration where you want to talk naturally, reference earlier topics, and occasionally fan out a request into multiple variations or a sequence of related tasks.
- [Waterfall Mode](./Waterfall.md) — Best for well-defined tasks where you want to see the full plan up front, review or edit it, and then let it run start-to-finish without further intervention.
