# Cognotik IntelliJ Plugin

Cognotik is an open-source AI coding assistant for IntelliJ IDEs that goes beyond autocomplete, offering high-level agentic tools to plan and execute complex development workflows directly inside your IDE.

## Getting Started

1. Open IntelliJ IDEA, GoLand, PyCharm, or another compatible JetBrains IDE.
2. Go to `Settings/Preferences` > `Plugins`.
3. Select the `Marketplace` tab and search for "AI Coding Assistant" or "Cognotik".
4. Click `Install` and restart the IDE when prompted.
5. Open `Settings/Preferences` > `Tools` > `Cognotik` and enter your API key(s) for your chosen AI provider(s) (e.g. OpenAI).
6. Configure preferred models and agent behavior as needed.
7. Use the `AI Tools` context menu in the editor or Project view, or open a dedicated Cognotik tool window, to start using agentic features, code editing, or voice-to-text input.

## Packaging & Launch

Cognotik is distributed as a standard IntelliJ plugin, installable directly from the JetBrains Marketplace like any other plugin. No separate download, installer, or manual setup is required beyond installing and configuring it through the IDE's Plugins settings — updates are also delivered through the Marketplace.

## See Also

Cognotik can also be run outside the IDE as a Desktop application or via the CLI, for workflows that don't require IntelliJ.
