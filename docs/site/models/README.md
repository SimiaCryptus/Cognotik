# Supported Models

Reference pages for each AI provider integration available in Cognotik via Bring-Your-Own-Key (BYOK) access.

- [Anthropic Models](./Anthropic.md) — Claude models from Anthropic, available through Cognotik via Bring-Your-Own-Key (BYOK) chat access.
- [AWS Bedrock](./Bedrock.md) — Chat access to models hosted on Amazon Bedrock via Cognotik's Bring-Your-Own-Key (BYOK) integration.
- [DeepSeek Models](./DeepSeek.md) — DeepSeek provides high-context chat models with reasoning ("thinking") support, accessible through Cognotik using your own DeepSeek API key.
- [ElevenLabs Models](./ElevenLabs.md) — ElevenLabs is primarily a text-to-speech (TTS), speech-to-text (STT), speech-to-speech, and generative audio provider.
- [Gemini Models](./Gemini.md) — Google's Gemini family of models, accessible through Cognotik using your own Gemini Developer API key.
- [Groq Models](./Groq.md) — Groq provides ultra-low-latency inference for a range of open-weight chat models, safety/guard models, compound agentic systems, transcription (Whisper), and text-to-speech (Orpheus) models.
- [Mistral Models](./Mistral.md) — Mistral AI provides a range of chat-capable large language models, from lightweight edge-optimized "Ministral" models to frontier-class multimodal "Large"/"Medium" models, plus specialist code and reasoning models.
- [ModelsLab Models](./ModelsLab.md) — Access ModelsLab's chat-completion API through Cognotik using your own API key.
- [Ollama Models](./Ollama.md) — Run local, self-hosted models through Ollama with Cognotik using your own compute — no per-token API fees.
- [OpenAI Models](./OpenAI.md) — Chat models available through OpenAI, accessible in Cognotik using your own API key (BYOK).
- [Perplexity Models](./Perplexity.md) — Perplexity provides an OpenAI-compatible chat completion API, accessible through Cognotik using your own API key.
