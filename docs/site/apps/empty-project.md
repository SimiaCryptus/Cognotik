# 🗂️ Empty Project

A blank Cognotik workspace, pre-loaded with a catalog of ready-to-use Dev Tools to kickstart any project.

## What It Does

Empty Project is exactly what it sounds like — a fresh workspace with no source code yet. But it isn't truly
empty: it comes with a built-in **Dev Tools catalog**, a lightweight home page listing every tool Cognotik offers
for planning, reviewing, building, and tracking your project. Open it up, browse the catalog, and pick the tool
that matches what you want to do next.

## How to Use It

1. Open the workspace and load `app.html` — it takes you straight to the tool catalog.
2. Use the search box or category filters to find a tool that matches your goal (planning, code review, building, or
   issue tracking).
3. Click a tool's card to open it, or click **README** to preview what it does first.
4. If you're starting completely from scratch, try **🌱 Greenfield Implementer** — describe your idea in a
   paragraph and let it plan out a spec, stack, and build tasks for you.
5. As your project grows, come back to the catalog anytime to pick the next tool you need.

## Why You'll Love It

- **No setup required** — the catalog just works, with no installs or build steps.
- **One place to find every tool** — search, filter by category, or browse by tags instead of hunting through docs.
- **Shareable views** — your search and filter choices are saved in the page link, so you can send a teammate
  straight to the tool you found.
- **Honest status** — tools that aren't available yet are clearly marked, so you always know what's ready to use.
- **A clear starting point** — if you don't know where to begin, Greenfield Implementer turns a single idea into a
  full project plan.

## Behind the Scenes

The catalog itself is simple by design — a searchable list of tools, each with its own README and entry point. When
you launch a tool, it takes over with its own guided steps (for example, Greenfield Implementer walks through
planning stages, while Reviewer walks through code-review stages). Nothing happens until you choose a tool and
start it.
