# 🧙 System Wizard

**Describe what you want your computer to do — the wizard writes and runs the script for you.**

No coding required. Just tell System Wizard your goal in plain English, and watch it turn into a working, tested shell script.

## What It Does

You describe a task you want your computer to perform — cleaning up old files, gathering system info, backing up folders, whatever you need — using everyday language. System Wizard takes it from there: it writes a shell script to accomplish your goal, runs it, and automatically fixes any errors it hits along the way. You end up with a working script and a clear log of exactly what happened.

## How to Use It

1. Open the **Goal** tab and describe what you want to accomplish — the more detail, the better. Or click an example prompt to get started instantly.
2. Click **▶ Run Entire Pipeline** and watch the live progress log as your goal is saved, a script is generated, and it's run and auto-fixed.
3. Switch to the **Results** tab to see the final script and full execution log.
4. Copy or download your script straight from the Results tab.

- **Generate** — the AI writes a shell script tailored to your goal
- **Run & Fix** — the script runs, and any errors are automatically diagnosed and repaired
- **Results** — the final script and execution log are packaged up for you to review
