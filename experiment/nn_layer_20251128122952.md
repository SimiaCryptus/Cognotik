# Formal Definition

## Forward Function

$$\begin{align}
\Delta t_{ij} &= t_j - t_i \\
\|\Delta \vec{s}_{ij}\| &= \sqrt{\sum_{k=1}^{D-1} (\Delta s_{ij}^{(k)})^2} \\
z_{ij} &= \|\Delta \vec{s}_{ij}\|_2 + i \cdot c \cdot \Delta t_{ij} \\
\tilde{z}_{ij} &= (W_{\Re} + i W_{\Im}) \cdot z_{ij} + (b_{\Re} + i b_{\Im}) \\
\mathbf{y}_b &= [\tilde{z}_{01}, \tilde{z}_{02}, \ldots, \tilde{z}_{(N-2)(N-1)}] \in \mathbb{C}^{N(N-1)/2}
\end{align}$$

**Notation:** For input X ∈ ℝ^(B×N×D) decomposed as x_i = (t_i, s_i), compute pairwise Minkowski intervals encoded as complex numbers: z_ij = ||Δs_ij||_2 + i·c·Δt_ij, then apply learnable complex transformation: ỹ_b^(k) = (W_real + i·W_imag)·z_ij + (b_real + i·b_imag), where k = i(2N-i-1)/2 + (j-i-1) indexes the pair (i,j) with i<j over all N(N-1)/2 pairs. Output: Y ∈ ℂ^(B×N(N-1)/2)

## Domain Constraints

- Input shape: X ∈ ℝ^(B×N×D) with D ≥ 2, N ≥ 2
- First dimension interpreted as time: t_i = X_{b,i,0}
- Spatial components: s_i = X_{b,i,1:D} ∈ ℝ^(D-1)
- Temporal component t_i ∈ ℝ (unbounded)
- Speed of light parameter: c > 0 (strictly positive, learnable)
- Complex weights: W_real, W_imag ∈ ℝ
- Complex bias: b_real, b_imag ∈ ℝ
- Causal preservation constraint: W_real > 0 (enforced via softplus)

## Range

Output Y ∈ ℂ^(B×N(N-1)/2) encodes pairwise spacetime intervals as complex numbers. Magnitude |z_ij| = √(||Δs_ij||² + c²(Δt_ij)²) represents separation scale in (s,ct) plane. Phase φ_ij = arctan(c·Δt_ij/||Δs_ij||) ∈ (-π/2, π/2) encodes causal structure: timelike intervals (d²_ij < 0) have |φ_ij| > π/4, spacelike intervals (d²_ij > 0) have |φ_ij| < π/4, null intervals (d²_ij = 0) have |φ_ij| = π/4. Minkowski squared interval: d²_ij = -c²(Δt_ij)² + ||Δs_ij||²

## Parameter Initialization

- Speed of light c: Initialize to c₀ = 1.0 (natural units, allows gradient-based adaptation)
- W_real: Initialize from 𝒩(1, 0.01) for near-identity initialization preserving causal structure
- W_imag: Initialize from 𝒩(0, 0.01) for small imaginary component ensuring stability
- b_real: Initialize to 0 (zero bias)
- b_imag: Initialize to 0 (zero bias)
- Alternative (Glorot/Xavier for complex weights): W_real, W_imag ~ 𝒰(-√(1/2), √(1/2)) with variance 1/(n_in + n_out) = 1/2 per component
- Enforce W_real > 0 via W_real = softplus(Ŵ_real) to preserve causal ordering: sgn(Im(ỹ_ij)) = sgn(Δt_ij)

# Gradient Derivation (Backward Pass)

## Chain Rule Application

The backpropagation follows the computational graph through multiple stages: (1) Upstream gradients g^Re and g^Im decompose the complex loss gradient. (2) Bias gradients are direct: ∂L/∂b_Re sums g^Re; ∂L/∂b_Im sums g^Im. (3) Weight gradients apply chain rule through the complex multiplication: ∂L/∂W_Re = Σ(g^Re·r_ij + g^Im·c·Δt_ij); ∂L/∂W_Im = Σ(-g^Re·c·Δt_ij + g^Im·r_ij). (4) Speed of light c gradient: ∂L/∂c = Σ Δt_ij(-g^Re·W_Im + g^Im·W_Re). (5) Intermediate variables: α_ij = ∂L/∂r_ij = g^Re·W_Re + g^Im·W_Im; β_ij = ∂L/∂Δt_ij = c(-g^Re·W_Im + g^Im·W_Re). (6) Input gradients split into temporal (k=0) and spatial (k≥1) components, with spatial gradients normalized by r_ij to account for the L2 norm operation.

## Gradient with Respect to Input

$$\frac{\partial L}{\partial X_{b,n,0}} = \sum_{i<n} \beta_{b,in} - \sum_{j>n} \beta_{b,nj}, \quad \beta_{b,ij} = c\left(-g_{b,p}^{\Re} W_{\Im} + g_{b,p}^{\Im} W_{\Re}\right); \quad \frac{\partial L}{\partial X_{b,n,k}} = \sum_{i<n} \frac{\alpha_{b,in} \cdot \Delta s_{in}^{(k)}}{r_{in}} - \sum_{j>n} \frac{\alpha_{b,nj} \cdot \Delta s_{nj}^{(k)}}{r_{nj}}, \quad \alpha_{b,ij} = g_{b,p}^{\Re} W_{\Re} + g_{b,p}^{\Im} W_{\Im}$$

**Expression:** ∂L/∂X_{b,n,0} = Σ_{i<n} β_{b,in} - Σ_{j>n} β_{b,nj}, where β_{b,ij} = c(-g_{b,p}^Re·W_Im + g_{b,p}^Im·W_Re); ∂L/∂X_{b,n,k} = Σ_{i<n} (α_{b,in}·Δs_{in}^{(k)}/r_{in}) - Σ_{j>n} (α_{b,nj}·Δs_{nj}^{(k)}/r_{nj}), where α_{b,ij} = g_{b,p}^Re·W_Re + g_{b,p}^Im·W_Im, for k ∈ {1,...,D-1}

## Parameter Gradients

### ∂L/∂b_real

$$\frac{\partial L}{\partial b_{\Re}} = \sum_{b=1}^{B} \sum_{i<j} g_{b,p}^{\Re}$$

**Expression:** ∂L/∂b_Re = Σ_{b,i<j} g_{b,p}^Re

### ∂L/∂b_imag

$$\frac{\partial L}{\partial b_{\Im}} = \sum_{b=1}^{B} \sum_{i<j} g_{b,p}^{\Im}$$

**Expression:** ∂L/∂b_Im = Σ_{b,i<j} g_{b,p}^Im

### ∂L/∂W_real

$$\frac{\partial L}{\partial W_{\Re}} = \sum_{b=1}^{B} \sum_{i<j} \left( g_{b,p}^{\Re} \cdot r_{ij} + g_{b,p}^{\Im} \cdot c \cdot \Delta t_{ij} \right)$$

**Expression:** ∂L/∂W_Re = Σ_{b,i<j} (g_{b,p}^Re·r_{ij} + g_{b,p}^Im·c·Δt_{ij})

### ∂L/∂W_imag

$$\frac{\partial L}{\partial W_{\Im}} = \sum_{b=1}^{B} \sum_{i<j} \left( -g_{b,p}^{\Re} \cdot c \cdot \Delta t_{ij} + g_{b,p}^{\Im} \cdot r_{ij} \right)$$

**Expression:** ∂L/∂W_Im = Σ_{b,i<j} (-g_{b,p}^Re·c·Δt_{ij} + g_{b,p}^Im·r_{ij})

### ∂L/∂c

$$\frac{\partial L}{\partial c} = \sum_{b=1}^{B} \sum_{i<j} \Delta t_{ij} \left( -g_{b,p}^{\Re} \cdot W_{\Im} + g_{b,p}^{\Im} \cdot W_{\Re} \right)$$

**Expression:** ∂L/∂c = Σ_{b,i<j} Δt_{ij}(-g_{b,p}^Re·W_Im + g_{b,p}^Im·W_Re)

## Computational Graph

```
X ∈ ℝ^(B×N×D) → [temporal: t_i, t_j (index 0); spatial: s_i, s_j (indices 1:D)] → Δt_ij = t_j - t_i; Δs_ij = s_j - s_i → r_ij = ||Δs_ij||_2 → z_ij = r_ij + i·c·Δt_ij → (W_real + i·W_imag)·z_ij + (b_real + i·b_imag) → Y ∈ ℂ^(B×N(N-1)/2). Complex multiplication expands to: ỹ_ij^Re = W_Re·r_ij - W_Im·c·Δt_ij + b_Re; ỹ_ij^Im = W_Im·r_ij + W_Re·c·Δt_ij + b_Im
```

# Higher-Order Derivative Analysis

## Hessian Structure

Block-structured Hessian over combined parameter-input space (BND + 4 dimensions). Decomposes into 3×3 blocks: H_XX (input-input), H_XW (input-weight), H_Xb (input-bias), H_WW (weight-weight), H_Wb (weight-bias), H_bb (bias-bias). Key sparsity: H_XX has zero cross-batch coupling; within-batch non-zero only for spatially adjacent nodes or paired indices. Spatial components exhibit projection operator structure P_perp = I - s_hat*s_hat^T with rank D-1.

## Eigenvalue Bounds

Spatial block eigenvalues: λ_min ≥ 0, λ_max ≤ Σ_p |α_p|/r_p. Projection operator P_perp has eigenvalues: λ=1 (multiplicity D-2, orthogonal to separation), λ=0 (multiplicity 1, along separation). Condition number κ(H) ≈ O(r_max/r_min) × O(max(|W_Re|², |W_Im|², c²)). Critical singularity: κ→∞ as r_p→0 (coincident points). Weight block eigenvalues depend on Σ r_p² and Σ(Δt_p)² distributions.

## Second Derivatives

### spatial_same_node

$$∂²L/(∂X_{b,n,k}∂X_{b,n,l}) = Σ_{i<n} (α_{b,in}/r_{in})P_{kl}^⊥(ŝ_{in}) + Σ_{j>n} (α_{b,nj}/r_{nj})P_{kl}^⊥(ŝ_{nj}), where P_{kl}^⊥ = δ_{kl} - ŝ^{(k)}ŝ^{(l)} is projection onto hyperplane orthogonal to Δs$$

### spatial_cross_node

$$∂²L/(∂X_{b,n,k}∂X_{b,m,l}) = -(α_{b,nm}/r_{nm})P_{kl}^⊥(ŝ_{nm}) for valid pairs (m,n), zero otherwise$$

### temporal_temporal

$$∂²L/(∂X_{b,n,0}∂X_{b,m,0}) = c² Σ_pairs [W_Im² ∂²L/(∂(z̃_p^Re)²) - 2W_ReW_Im ∂²L/(∂z̃_p^Re∂z̃_p^Im) + W_Re² ∂²L/(∂(z̃_p^Im)²)]$$

### temporal_spatial_mixed

$$∂²L/(∂X_{b,n,0}∂X_{b,m,k}) involves cross-terms: (∂α_{b,ij}/∂X_{b,m,0})(Δs_p^{(k)}/r_p) where ∂α/∂X_{b,m,0} = (∂g_p^Re/∂X_{b,m,0})W_Re + (∂g_p^Im/∂X_{b,m,0})W_Im$$

### weight_weight

$$H_WW = Σ_{b,p} [(z_p^Re)² z_p^Re·z_p^Im; z_p^Re·z_p^Im (z_p^Im)²] ⊗ H_z̃z̃^{(b,p)}, where H_z̃z̃ is loss Hessian w.r.t. complex outputs$$

### bias_bias

$$H_bb = Σ_{b,p} H_z̃z̃^{(b,p)}, independent of input/weight structure$$

### input_weight_mixed

$$∂²L/(∂X_{b,n,k}∂W_Re) = Σ_pairs (Δs_p^{(k)}/r_p)[∂g_p^Re/∂W_Re + W_Re ∂²L/(∂z̃_p^Re∂W_Re)]$$

## Curvature Analysis

Layer is NOT globally convex. Non-convexity sources: (1) Radial nonlinearity r=||Δs|| creates curved loss landscape; (2) Complex multiplication W_Re, W_Im interaction generates saddle points. Local convexity holds when α_p > 0 for all pairs. Saddle points occur at: (a) Lightcone boundaries r_ij = c|Δt_ij| where z_ij becomes purely real/imaginary; (b) Weight space saddles at W_Re = ±W_Im (phase alignment). Curvature along geodesics: d²L/dε² = Σ_p (α_p/r_p)||δX_p^⊥||², proportional to perturbation component orthogonal to separation vector, scaled by 1/r. Geometric interpretation: Hessian measures resistance to motion perpendicular to pairwise connections.

## Fisher Information Matrix

For complex normal outputs z̃ ~ CN(μ,Σ): F_θθ' = E[∂log p(z̃|θ)/∂θ · ∂log p(z̃|θ)/∂θ']. Weight Fisher: F_{W_Re,W_Re} = (1/σ²)Σ r_p², F_{W_Im,W_Im} = (c²/σ²)Σ(Δt_p)², F_{W_Re,W_Im} = (c/σ²)Σ r_p·Δt_p. Input Fisher: F_{X_{n,k},X_{n,l}} = (|W|²/σ²)Σ_pairs (Δs_p^{(k)}Δs_p^{(l)}/r_p²). Fisher matrix structure: F_WW = (1/σ²)[Σr_p² c·Σr_p·Δt_p; c·Σr_p·Δt_p c²Σ(Δt_p)²]. Determinant: det(F_WW) = (1/σ⁴)[Σr_p²·c²Σ(Δt_p)² - c²(Σr_p·Δt_p)²]. Fisher encodes data geometry: spatial variance dominates W_Re, temporal variance dominates W_Im.

## Natural Gradient Considerations

Natural gradient ∇̃_θ L = F^{-1}∇_θ L provides Riemannian optimization on probability manifold. Block-diagonal approximation: F ≈ diag(F_WW, F_XX) for computational efficiency. Weight natural gradient: ∇̃_W L = F_WW^{-1}∇_W L with F_WW^{-1} = (σ²/det(F_WW))[c²Σ(Δt_p)² -c·Σr_p·Δt_p; -c·Σr_p·Δt_p Σr_p²]. Geometric benefits: (1) Decorrelates W_Re, W_Im updates, removing spurious coupling; (2) Rescales spatial vs temporal contributions adaptively; (3) Automatically adjusts for spacetime interval distribution; (4) Invariant to reparameterization. Convergence: Natural gradient achieves faster convergence than Euclidean gradient, especially when Fisher is ill-conditioned. Practical implementation: Preconditioning with diag({r_p}_spatial, {1/c}_temporal, {1/r̄}_weights) approximates F^{-1} efficiently. Regularization: Add λΣ 1/(r_p² + ε) to prevent r_p→0 singularities, modifying Hessian by ΔH = 2λΣ(1/(r_p²+ε)²)[I - 2(r_p²/(r_p²+ε))ŝ_p·ŝ_p^T].

# Lyapunov Stability Analysis

## Lyapunov Function Candidate

$$V(θ) = L(θ) - L(θ*), where L is the loss function and θ* is a local/global minimum. Properties: V(θ) ≥ 0 for all θ, V(θ*) = 0, and ΔV_t ≈ -η||∇L||² + (η²/2)∇L^T H∇L < 0 along gradient descent trajectories.$$

## Stability Conditions

- Learning rate constraint: η < 2/λ_max(H) where H is the Hessian
- Weight bounds: ε/min|z_ij| < ||W||_ℂ < 1/max|z_ij| to avoid vanishing and exploding gradients
- Causal regularity: min_ij|r_ij² - c²Δt_ij²| > δ > 0 to maintain non-null separation
- Initialization condition: V(θ_0) < V_critical within basin of attraction
- Strong convexity with condition number κ = λ_max(H)/λ_min(H) bounded

## Equilibrium Analysis

Critical points satisfy ∇_θ L = 0. Hessian eigenvalue signature classifies equilibria: all λ_i > 0 indicates stable minimum, all λ_i < 0 indicates unstable maximum, mixed signs indicate saddle point. For MinkowskiCausalLayer, Hessian components depend on spatial separations r_ij = ||Δs_ij||_2 and temporal separations c·Δt_ij through the complex weight structure.

## Basin of Attraction

Local basin near stable equilibrium θ* satisfies B(θ*) ⊇ {θ : ||θ - θ*|| < 2/(η·L_H)}. Geometry decomposes as B = B_ℜ × B_ℑ with shape determined by ratio ρ = E[r_ij²]/E[(c·Δt_ij)²]: elongated along W_ℑ when ρ ≫ 1, along W_ℜ when ρ ≪ 1, approximately spherical when ρ ≈ 1.

## Convergence Rate

Linear convergence for μ-strongly convex loss: V(θ_t) ≤ (1 - 2ημL/(μ+L))^t V(θ_0). Convergence time T_ε = O(κ log(1/ε)) where κ is condition number. Well-conditioned (κ~1): O(log(1/ε)); ill-conditioned (κ≫1): O(κ log(1/ε)); near saddle: sub-linear O(1/t).

## Potential Instability Modes

- ⚠️ Exploding gradients when ||W||_ℂ > 1/max_ij|z_ij|, triggered by large spatial separations ||Δs_ij|| → ∞, large temporal separations |Δt_ij| → ∞, or large speed of light c → ∞
- ⚠️ Vanishing gradients when ||W||_ℂ < ε/min_ij|z_ij|, caused by coincident events z_ij → 0, small weight initialization, or numerical underflow
- ⚠️ Lightcone boundary instability at null separation r_ij ≈ c|Δt_ij| where |z_ij|² → 0, creating gradient discontinuities and ill-conditioned Hessian
- ⚠️ Ill-conditioning from large condition number κ = max_ij|z_ij|²/min_ij|z_ij|² when spacetime coordinates have disparate magnitudes

# Lipschitz Continuity Analysis

## Forward Function Lipschitz Constant

$$L_f = √(2(N-1)) · max(1, c) · √(W_ℝ² + W_ℑ²), where N is number of events, c is speed of light parameter, and W_ℂ is the complex weight matrix. This is derived from composition of three Lipschitz operators: pairwise differences (L_𝒫 = √(2(N-1))), complex interval construction (L_𝒵 = max(1,c)), and affine transformation (L_𝒜 = |W_ℂ|).$$

## Gradient Lipschitz Constant (Smoothness)

$$Unregularized: L_∇f = ∞ due to non-Lipschitz behavior of spatial norm normalization φ(s) = s/‖s‖₂ at s=0, with Hessian spectral norm ‖∇²r‖₂ = 1/r → ∞ as r→0. Regularized with ε-smoothing: L_∇f^(ε) = √(2(N-1))/ε · (|W_ℝ| + |W_ℑ|), bounded by regularization parameter ε.$$

## Spectral Norm Bounds

‖J_f‖₂ ≤ √2 · √(1+c²) · √(W_ℝ² + W_ℑ²). Jacobian has structured sparsity with each output depending only on two events (X_i, X_j), yielding 2D non-zero entries per row. Effective rank ≈ min(N(N-1)/2, ND). Spectral norm of pairwise difference operator ‖J_𝒫‖₂ = √2 (complete graph incidence matrix), and complex construction ‖J_𝒵‖₂ ≤ √(1+c²).

## Gradient Flow Analysis

Gradient magnitude bounds: ‖∂L/∂X_{b,n,0}‖ ≤ (N-1)·c·(|W_ℝ|+|W_ℑ|)·‖g_b‖_∞ for temporal component, and ‖∂L/∂X_{b,n,k}‖ ≤ (N-1)·(|W_ℝ|+|W_ℑ|)·‖g_b‖_∞ for spatial. Stability requires learning rate η < 2ε/(√(2(N-1))(|W_ℝ|+|W_ℑ|)). Temporal gradients uniform across events; spatial gradients concentrate on nearby pairs with E[‖∂L/∂X_{:,:,k}‖²] ∝ Σ(1/r_ij²), causing potential gradient explosion for clustered events.

## Smoothness Properties

- Forward function is Lipschitz continuous with constant L_f = √(2(N-1))·max(1,c)·|W_ℂ|
- Unregularized gradient is non-Lipschitz due to singularity at zero spatial separation (r_ij=0)
- Hessian of spatial norm has eigenvalues: λ₁=0 (radial) and λ₂...λ_D=1/r (tangential), with unbounded spectral norm as r→0
- ε-regularization r_ε = √(‖Δs‖₂² + ε²) bounds smoothness constant to O(1/ε)
- Jacobian exhibits structured sparsity: each output depends only on two input events
- Gradient concentration on nearby event pairs creates risk of gradient explosion for clustered spatial configurations
- Temporal gradients are uniform and independent of spatial configuration
- Recommended ε-regularization: ε ~ 10⁻⁶ to maintain causal structure while ensuring training stability
- Generalization bound via Rademacher complexity: ℛ_n(ℱ) ≤ L_f·diam(𝒳)/√n
- Adversarial robustness: |f(X+δ)-f(X)| ≤ L_f‖δ‖_F

# Numerical Stability Analysis

## Overflow Conditions

- ⚠️ Squaring spatial differences: |Δs| > 10^19 (float32) causes squared magnitude overflow
- ⚠️ Summation of squared components: D · max(Δs²) > 10^38 for large D
- ⚠️ Weight-input product: |W| · |z| > 10^38 depends on initialization
- ⚠️ Overflow in downstream operations when complex interval magnitude exceeds 1e6

## Underflow Conditions

- ⚠️ Square root computation: Σ(Δs)² < 10^-45 (float32) causes gradient issues
- ⚠️ Nearly coincident points: |Δs⃗|₂ ≈ 0 leads to undefined gradients
- ⚠️ Complex magnitude near zero: both real and imaginary components ≈ 0
- ⚠️ Division by norm in backward pass when |Δs⃗|₂ → 0

## Precision Recommendations

- Training (general): Use float32 for balance of speed and stability
- Large spatial scales (|Δs| > 10⁴): Use float64 to prevent squared overflow
- Inference only: float16 acceptable with proper scaling
- High-precision physics: float64 to preserve causal structure
- Mixed precision training: float32 master weights with float16 compute and loss scaling
- Critical operations (spatial norm, time differences with |t| > 1e4): Always use float32 minimum

## Stabilization Techniques

- ✅ Safe Euclidean norm: Scale before squaring, add epsilon to sqrt, then rescale
- ✅ Stable complex construction: Clamp real and imaginary parts to prevent overflow (max_val=1e6)
- ✅ Log-space alternative: Use log-space representation for extreme scales
- ✅ Input normalization: Adaptive normalization with running statistics for spatial and temporal scales
- ✅ Gradient safety: Add epsilon (1e-8) to prevent division by zero in norm gradients
- ✅ Bounded interval construction: Clamp complex Minkowski intervals to prevent downstream overflow

## Gradient Clipping

Global norm clipping (max_grad_norm=1.0) as primary defense; Per-parameter clipping for complex weights (W_real_clip=10.0, W_imag_clip=10.0, bias_clip=5.0); Adaptive gradient clipping (AGC) scaled by parameter norm with clip_factor=0.01; Complex-aware gradient clipping that preserves phase by scaling both real and imaginary components equally; Adaptive clipping at 99th percentile for dynamic threshold adjustment

### Forward Pass

```python_pytorch
def forward(self, X: torch.Tensor) -> torch.Tensor:
    B, N, D = X.shape
    num_pairs = N * (N - 1) // 2
    
    t = X[:, :, 0]
    s = X[:, :, 1:]
    
    idx_i, idx_j = torch.triu_indices(N, N, offset=1, device=X.device)
    
    delta_t = t[:, idx_j] - t[:, idx_i]
    delta_s = s[:, idx_j, :] - s[:, idx_i, :]
    
    r = torch.sqrt(torch.sum(delta_s ** 2, dim=-1) + 1e-12)
    
    z_real = r
    z_imag = self.c * delta_t
    
    out_real = self.W_real * z_real - self.W_imag * z_imag + self.b_real
    out_imag = self.W_real * z_imag + self.W_imag * z_real + self.b_imag
    
    output = torch.complex(out_real, out_imag)
    
    return output
```

### Backward Pass

```python_pytorch
@staticmethod
def backward(ctx, grad_output: torch.Tensor) -> Tuple[torch.Tensor, ...]:
    X, c, W_real, W_imag, delta_t, delta_s, r = ctx.saved_tensors
    idx_i, idx_j = ctx.idx_i, ctx.idx_j
    
    B, N, D = X.shape
    
    g_real = grad_output.real
    g_imag = grad_output.imag
    
    grad_b_real = g_real.sum()
    grad_b_imag = g_imag.sum()
    
    grad_W_real = (g_real * r + g_imag * c * delta_t).sum()
    grad_W_imag = (-g_real * c * delta_t + g_imag * r).sum()
    
    grad_c = (delta_t * (-g_real * W_imag + g_imag * W_real)).sum()
    
    grad_X = torch.zeros_like(X)
    
    alpha = g_real * W_real + g_imag * W_imag
    beta = c * (-g_real * W_imag + g_imag * W_real)
    
    r_safe = r.clamp(min=1e-12)
    spatial_grad_factor = (alpha / r_safe).unsqueeze(-1) * delta_s
    
    for b in range(B):
        grad_X[b, :, 1:].index_add_(0, idx_j, spatial_grad_factor[b])
        grad_X[b, :, 1:].index_add_(0, idx_i, -spatial_grad_factor[b])
    
    for b in range(B):
        grad_X[b, :, 0].index_add_(0, idx_j, beta[b])
        grad_X[b, :, 0].index_add_(0, idx_i, -beta[b])
    
    return grad_X, grad_c, grad_W_real, grad_W_imag, grad_b_real, grad_b_imag
```

```python_jax
    W_real = params.W_real[0]
    W_imag = params.W_imag[0]

    z_imag = c * delta_t

    prod_imag = W_real * z_imag + W_imag * z_real
```

```python_jax
    r = jnp.sqrt(jnp.sum(delta_s ** 2, axis=-1) + 1e-8)

    grad_b_imag = jnp.sum(grad_y_imag)
```

```latex_mathematical
def forward(self, X: torch.Tensor) -> Tuple[torch.Tensor, Dict]:
    """
    Forward pass computing Minkowski causal intervals.
    
    Args:
        X: Input tensor of shape (B, N, D) where:
           - B: batch size
           - N: number of points
           - D: dimensions (first is temporal, rest are spatial)
    
    Returns:
        Y: Output tensor of shape (B, N(N-1)/2) with complex values
        cache: Dictionary containing cached values for backward pass
    """
    B, N, D = X.shape
    P = N * (N - 1) // 2  # Number of pairs
    
    # Initialize output and cache
    Y = torch.zeros(B, P, dtype=torch.complex64, device=X.device)
    cache = {
        'delta_t': torch.zeros(B, P, device=X.device),
        'r': torch.zeros(B, P, device=X.device),
        'delta_s': torch.zeros(B, P, D-1, device=X.device)
    }
    
    # Process each batch
    for b in range(B):
        p = 0
        for i in range(N - 1):
            for j in range(i + 1, N):
                # Step 1: Compute temporal difference
                delta_t = X[b, j, 0] - X[b, i, 0]
                
                # Step 2: Compute spatial differences and Euclidean distance
                delta_s = X[b, j, 1:] - X[b, i, 1:]
                r = torch.norm(delta_s, p=2)
                
                # Step 3: Construct complex Minkowski interval
                z_re = r
                z_im = self.c * delta_t
                
                # Step 4: Apply complex affine transformation
                # tilde_z = (W_re + i*W_im) * (z_re + i*z_im) + (b_re + i*b_im)
                tilde_z_re = self.W_re * z_re - self.W_im * z_im + self.b_re
                tilde_z_im = self.W_im * z_re + self.W_re * z_im + self.b_im
                
                Y[b, p] = tilde_z_re + 1j * tilde_z_im
                
                # Cache values for backward pass
                cache['delta_t'][b, p] = delta_t
                cache['r'][b, p] = r
                cache['delta_s'][b, p, :] = delta_s
                
                p += 1
    
    return Y, cache
```

### Backward Pass

```latex_mathematical
def backward(self, G: torch.Tensor, cache: Dict, X: torch.Tensor) -> Tuple[torch.Tensor, Dict]:
    """
    Backward pass computing gradients.
    
    Args:
        G: Upstream gradient tensor of shape (B, P) with complex values
        cache: Cached values from forward pass
        X: Original input tensor
    
    Returns:
        grad_X: Gradient with respect to input
        grad_params: Dictionary of parameter gradients
    """
    B, N, D = X.shape
    P = N * (N - 1) // 2
    
    # Initialize gradients
    grad_X = torch.zeros_like(X)
    grad_b_re = torch.tensor(0.0, device=X.device)
    grad_b_im = torch.tensor(0.0, device=X.device)
    grad_W_re = torch.tensor(0.0, device=X.device)
    grad_W_im = torch.tensor(0.0, device=X.device)
    grad_c = torch.tensor(0.0, device=X.device)
    
    # Extract upstream gradient components
    g_re = G.real
    g_im = G.imag
    
    # Process each pair
    for b in range(B):
        p = 0
        for i in range(N - 1):
            for j in range(i + 1, N):
                # Retrieve cached values
                delta_t = cache['delta_t'][b, p]
                r = cache['r'][b, p]
                delta_s = cache['delta_s'][b, p, :]
                
                # Upstream gradient components
                g_re_p = g_re[b, p]
                g_im_p = g_im[b, p]
                
                # Accumulate bias gradients
                grad_b_re = grad_b_re + g_re_p
                grad_b_im = grad_b_im + g_im_p
                
                # Accumulate weight gradients
                grad_W_re = grad_W_re + g_re_p * r + g_im_p * self.c * delta_t
                grad_W_im = grad_W_im - g_re_p * self.c * delta_t + g_im_p * r
                
                # Accumulate speed of light gradient
                grad_c = grad_c + delta_t * (-g_re_p * self.W_im + g_im_p * self.W_re)
                
                # Compute auxiliary quantities
                alpha = g_re_p * self.W_re + g_im_p * self.W_im
                beta = self.c * (-g_re_p * self.W_im + g_im_p * self.W_re)
                
                # Input gradients for temporal coordinate
                grad_X[b, i, 0] = grad_X[b, i, 0] - beta
                grad_X[b, j, 0] = grad_X[b, j, 0] + beta
                
                # Input gradients for spatial coordinates
                r_safe = r + self.epsilon
                for k in range(D - 1):
                    gamma_k = alpha * delta_s[k] / r_safe
                    grad_X[b, i, k + 1] = grad_X[b, i, k + 1] - gamma_k
                    grad_X[b, j, k + 1] = grad_X[b, j, k + 1] + gamma_k
                
                p += 1
    
    grad_params = {
        'c': grad_c,
        'W_re': grad_W_re,
        'W_im': grad_W_im,
        'b_re': grad_b_re,
        'b_im': grad_b_im
    }
    
    return grad_X, grad_params
```

# Computational Complexity Analysis

## Time Complexity

| Pass | Complexity |
|------|------------|
| Forward | O(B · N² · D) where B is batch size, N is number of points, and D is dimensionality. Dominated by pairwise spatial difference computation and spatial norm calculations across all N(N-1)/2 pairs. |
| Backward | O(B · N² · D) - symmetric to forward pass. Gradient computation for inputs requires backpropagation through pairwise differences (O(B·N²·D)), while gradients for parameters c, W_ℝ, W_ℑ, b_ℝ, b_ℑ are O(B·N²) each. |

## Space Complexity

O(B · N² · D) for activations (pairwise differences dominate) + O(B · N² · D) for gradient storage during backprop. Parameter storage is O(1) with only 5 scalar parameters. Total: O(B · N² · D) activation + gradient memory.

## Memory Bandwidth

O(B · N² · D) bytes. Low arithmetic intensity - memory-bound operation. Forward pass reads O(B·N·D) input data but writes O(B·N²·D) pairwise differences. Bandwidth bottleneck from irregular pairwise indexing patterns when accessing input coordinates.

## Parallelization

Excellent GPU parallelization: O(B·N²) embarrassingly parallel threads (one per pair). Each thread independently computes spatial norm and complex transformation. Spatial norm computation within each thread allows parallel reduction over D dimensions. Data parallelism across batch dimension B is ideal with no cross-batch dependencies. Sequence parallelism over N is complex due to all-pairs dependencies. Main limitation: quadratic N scaling makes this impractical for N>1000 without sparse approximations or hierarchical methods (LSH, tree-based).
