🚀 Batch Execution

Run the full pipeline from design to tested build, or run individual stages below.

1 📐 Design pending

Analyze the idea and produce a comprehensive design document capturing technology choices, architecture decisions, and project structure.

2 🏗️ Scaffold pending

Generate the project skeleton: package.json, config files, directory structure, and minimal entry points based on the design.

3 📥 Install Dependencies pending

Run npm install to fetch and resolve all project dependencies. Auto-fixes version conflicts and peer dependency issues.

4 💻 Implement pending

Write the full application source code — components, styles, assets, and entry points — according to the design and idea documents.

5 🧪 Write Tests pending

Generate comprehensive test files — unit tests, component tests, and integration tests — for the implemented source code.

6 🔨 Build pending

Run npm run build and auto-fix any errors — TypeScript issues, import errors, missing dependencies, bundler config problems.

7 ✅ Run Tests pending

Run npm test and auto-fix any failures — assertion errors, import issues, configuration problems, missing mocks.

8 🔧 Update pending

Apply iterative changes from the Notes tab — bug fixes, feature additions, design changes. Then re-build and re-test.
