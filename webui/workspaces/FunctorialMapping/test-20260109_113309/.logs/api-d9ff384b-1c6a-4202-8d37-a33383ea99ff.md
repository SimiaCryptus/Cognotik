## Categories

To formalize these domains, we first define the underlying algebraic structure common to both: the **Tropical Semiring** (specifically the min-plus algebra).

Let $\mathbb{R}_{\min} = (\mathbb{R} \cup \{\infty\}, \oplus, \otimes)$ be the semiring where:
*   The addition operator is minimization: $a \oplus b = \min(a, b)$.
*   The multiplication operator is standard addition: $a \otimes b = a + b$.
*   The additive identity is $\infty$.
*   The multiplicative identity is $0$.

---

### 1. Source Category: The Weighted Path Category $\mathcal{G}_W$

This category formalizes a weighted directed graph as a structure where morphisms represent the "cost" of travel between nodes.

**Objects: $\text{Ob}(\mathcal{G}_W)$**
*   The objects are the set of vertices (nodes) $V$ of the graph.
*   $A, B, C \in \text{Ob}(\mathcal{G}_W)$.

**Morphisms: $\text{Hom}_{\mathcal{G}_W}(A, B)$**
*   A morphism $f: A \to B$ is a path from node $A$ to node $B$.
*   Each morphism is associated with a weight $w(f) \in \mathbb{R} \cup \{\infty\}$.
*   If multiple paths exist between $A$ and $B$, each unique path is a distinct morphism. (Alternatively, if we only care about the shortest path, the category becomes a preorder/thin category where $\text{Hom}(A, B)$ is the minimum weight).

**Composition: $\circ$**
*   Given $f: A \to B$ and $g: B \to C$, the composition $g \circ f: A \to C$ is the concatenation of the paths.
*   The weight of the composed morphism is the tropical product of the weights:
    $$w(g \circ f) = w(f) \otimes w(g) = w(f) + w(g)$$

**Identity Morphism: $\text{id}_A$**
*   For every node $A$, the identity morphism $\text{id}_A$ is the empty path (staying at the node).
*   The weight is the tropical multiplicative identity: $w(\text{id}_A) = 0$.

---

### 2. Target Category: The Tropical Linear Category $\mathcal{V}ect(\mathbb{R}_{\min})$

This category formalizes transitions as linear transformations within tropical geometry.

**Objects: $\text{Ob}(\mathcal{V}ect(\mathbb{R}_{\min}))$**
*   The objects are finite-dimensional tropical vector spaces.
*   An object $V_n$ is the semimodule $(\mathbb{R} \cup \{\infty\})^n$.

**Morphisms: $\text{Hom}(V_n, V_m)$**
*   A morphism is a tropical matrix $M \in \text{Mat}_{m \times n}(\mathbb{R}_{\min})$.
*   This matrix represents a tropical linear map $L: \mathbb{R}_{\min}^n \to \mathbb{R}_{\min}^m$.
*   The transformation of a vector $x$ is given by:
    $$L(x)_i = \bigoplus_{j=1}^n (M_{ij} \otimes x_j) = \min_{j=1 \dots n} (M_{ij} + x_j)$$

**Composition: $\circ$**
*   Given $A: V_n \to V_m$ and $B: V_m \to V_p$, the composition $B \circ A: V_n \to V_p$ is defined by tropical matrix multiplication.
*   The resulting matrix $C = B \otimes A$ has entries:
    $$C_{ij} = \bigoplus_{k=1}^m (B_{ik} \otimes A_{kj}) = \min_{k=1 \dots m} (B_{ik} + A_{kj})$$
*   This composition is associative, following the associativity of the tropical semiring.

**Identity Morphism: $I_n$**
*   The identity morphism for $V_n$ is the tropical identity matrix $I \in \text{Mat}_{n \times n}(\mathbb{R}_{\min})$:
    $$I_{ij} = \begin{cases} 0 & \text{if } i = j \\ \infty & \text{if } i \neq j \end{cases}$$

---

| Feature | Source Category ($\mathcal{G}_W$) | Target Category ($\mathcal{V}ect(\mathbb{R}_{\min})$) |
| :--- | :--- | :--- |
| **Objects** | Nodes $v \in V$ | Vector spaces $\mathbb{R}_{\min}^n$ |
| **Morphisms** | Paths (Weighted) | Tropical Matrices $M$ |
| **Composition** | Path Concatenation | Tropical Matrix Multiplication |
| **Weight Logic** | Summation ($+$) | Min-Plus Matrix Product |
| **Identity** | Self-loop with weight $0$ | Identity Matrix ($0$ on diag, $\infty$ off) |

## Functor

To construct a covariant functor $F: \mathcal{G}_W \to \mathcal{V}ect(\mathbb{R}_{\min})$, we must define a mapping that preserves the categorical structure of weighted paths and translates them into the language of tropical linear algebra.

---

### 1. Mapping of Objects
For every object (node) in the source category, we map it to the simplest non-trivial tropical vector space.

*   **Definition:** For every node $A \in \text{Ob}(\mathcal{G}_W)$, the functor $F$ assigns:
    $$F(A) = V_1$$
    where $V_1$ is the 1-dimensional tropical vector space $(\mathbb{R} \cup \{\infty\})^1$.

*   **Intuition:** Every node is treated as a one-dimensional state space. While all nodes map to the same object $V_1$ in the target category, their distinct identities are maintained through the morphisms (the paths) between them.

---

### 2. Mapping of Morphisms
For every morphism (path) in the source category, we map it to a tropical linear transformation (a matrix).

*   **Definition:** Let $f: A \to B$ be a path in $\mathcal{G}_W$ with weight $w(f)$. The functor $F$ maps this path to a $1 \times 1$ tropical matrix $M_f \in \text{Mat}_{1 \times 1}(\mathbb{R}_{\min})$:
    $$F(f) = [w(f)]$$
*   **Action:** This matrix represents a linear map $L: V_1 \to V_1$. When this map is applied to a tropical "vector" (a scalar $x$), the result is:
    $$L(x) = [w(f)] \otimes x = w(f) + x$$

---

### 3. Proof of Functoriality
To be a valid covariant functor, $F$ must satisfy two conditions: preservation of identities and preservation of composition.

#### A. Preservation of Identity
In $\mathcal{G}_W$, the identity morphism $\text{id}_A$ is the empty path with weight $w(\text{id}_A) = 0$.
In $\mathcal{V}ect(\mathbb{R}_{\min})$, the identity morphism for $V_1$ is the $1 \times 1$ tropical identity matrix $I_1 = [0]$.

Applying the functor to the identity:
$$F(\text{id}_A) = [w(\text{id}_A)] = [0] = I_1$$
Thus, **$F(\text{id}_A) = \text{id}_{F(A)}$**.

#### B. Preservation of Composition
Let $f: A \to B$ and $g: B \to C$ be two paths in $\mathcal{G}_W$.
The composition $g \circ f$ is the concatenation of paths, with weight:
$$w(g \circ f) = w(f) \otimes w(g) = w(f) + w(g)$$

Applying the functor to the composition:
$$F(g \circ f) = [w(g \circ f)] = [w(f) + w(g)]$$

Now, we compare this to the composition of the images in the target category (tropical matrix multiplication):
$$F(g) \circ F(f) = [w(g)] \otimes [w(f)]$$
According to the rules of tropical matrix multiplication for $1 \times 1$ matrices:
$$[w(g)] \otimes [w(f)] = [\min(w(g) + w(f))] = [w(g) + w(f)]$$

Since $[w(f) + w(g)] = [w(g) + w(f)]$, we have:
**$F(g \circ f) = F(g) \circ F(f)$**.

---

### Summary of the Functor $F$
*   **Object Logic:** Each node is viewed as a coordinate in a tropical system.
*   **Morphism Logic:** A path of weight $w$ is viewed as a "shift" operator in the tropical semiring.
*   **Result:** This functor successfully embeds the graph's path-weight structure into the framework of tropical linear transformations, where path concatenation is exactly equivalent to the composition of linear maps.

## Transported Problem

To transport the "Shortest Path Problem" from the source category $\mathcal{G}_W$ to the target category $\mathcal{V}ect(\mathbb{R}_{\min})$ using the functor $F$, we translate the graph-theoretic search into an algebraic optimization within the tropical semiring.

### The Problem in the Target Category: $\mathcal{V}ect(\mathbb{R}_{\min})$

**1. Identification of Objects**
The nodes $A$ and $D$ are represented by the same object in the target category:
$$F(A) = V_1, \quad F(D) = V_1$$
where $V_1$ is the 1-dimensional tropical vector space.

**2. Identification of Morphisms (The Hom-set)**
In the source category, the set of all paths from $A$ to $D$ is the hom-set $\text{Hom}_{\mathcal{G}_W}(A, D)$. Under the functor $F$, this corresponds to a set of tropical linear transformations $\mathcal{M}_{AD}$ in the target category:
$$\mathcal{M}_{AD} = \{ F(f) \mid f \in \text{Hom}_{\mathcal{G}_W}(A, D) \}$$
Each element $M \in \mathcal{M}_{AD}$ is a $1 \times 1$ tropical matrix $[w]$ representing a morphism $L: V_1 \to V_1$.

**3. The Objective Function (Tropical Summation)**
The "shortest" path weight corresponds to the **tropical sum** ($\oplus$) of all morphisms in the image of the hom-set. In $\mathbb{R}_{\min}$, the addition operator is defined as the minimum: $a \oplus b = \min(a, b)$.

**4. Formal Statement of the Problem**
Strictly in terms of the target category's structure, the problem is formulated as follows:

> Given the set of morphisms $\mathcal{M}_{AD} \subseteq \text{Hom}(V_1, V_1)$, find the morphism $M^* \in \text{Mat}_{1 \times 1}(\mathbb{R}_{\min})$ defined by the tropical sum of all morphisms in the set:
> $$M^* = \bigoplus_{M \in \mathcal{M}_{AD}} M$$
> where the operator $\bigoplus$ denotes the element-wise infimum (minimum) of the tropical matrices.

---

### Summary of the Transformation

| Source Category ($\mathcal{G}_W$) | Target Category ($\mathcal{V}ect(\mathbb{R}_{\min})$) |
| :--- | :--- |
| **Nodes $A$ and $D$** | Objects $V_1$ and $V_1$ |
| **A path $f: A \to D$** | A morphism $M \in \text{Hom}(V_1, V_1)$ |
| **Path weight $w(f)$** | The single entry of the $1 \times 1$ matrix $M$ |
| **Shortest Path Weight** | The **Tropical Sum** of the morphisms in the image of the hom-set |
| **Path Concatenation** | **Tropical Composition** (Matrix Multiplication) |

**The Result:** The shortest path problem is transformed into finding the **infimum of a family of linear transformations** in a 1-dimensional tropical modulespace.

## Target Solution

To solve the "Shortest Path Problem" within the target category $\mathcal{V}ect(\mathbb{R}_{\min})$, we apply the principles of tropical geometry and tropical linear algebra. In this domain, the classical operations of addition and multiplication are replaced by the tropical sum ($\min$) and the tropical product ($+$).

### 1. Algebraic Framework: The Tropical Semiring
The target category $\mathcal{V}ect(\mathbb{R}_{\min})$ is built over the tropical semiring $\mathbb{R}_{\min} = (\mathbb{R} \cup \{\infty\}, \oplus, \otimes)$, where:
*   **Tropical Addition ($\oplus$):** $a \oplus b = \min(a, b)$
*   **Tropical Multiplication ($\otimes$):** $a \otimes b = a + b$
*   **Additive Identity ($\epsilon$):** $\infty$ (since $\min(a, \infty) = a$)
*   **Multiplicative Identity ($e$):** $0$ (since $a + 0 = a$)

### 2. Translation of Morphisms
In the source category $\mathcal{G}_W$, a path $f: A \to D$ is composed of edges $e_1, e_2, \dots, e_k$. Under the functor $F$, these edges are mapped to $1 \times 1$ tropical matrices (scalars in $\mathbb{R}_{\min}$).

For a path $f = e_k \circ \dots \circ e_1$, the morphism in the target category is:
$$F(f) = F(e_k) \otimes F(e_{k-1}) \otimes \dots \otimes F(e_1)$$
Substituting the tropical operator:
$$F(f) = [w(e_k) + w(e_{k-1}) + \dots + w(e_1)]$$
This confirms that the tropical composition of morphisms corresponds exactly to the summation of weights along a path in the graph.

### 3. Construction of the Hom-set Image $\mathcal{M}_{AD}$
Based on the standard graph structure associated with this problem, we identify the set of all paths from $A$ to $D$ and their corresponding tropical morphisms:
*   **Path 1 ($p_1$):** $A \to B \to D$ with weights $w_{AB}=2, w_{BD}=5$.
    $$M_1 = [5] \otimes [2] = [5 + 2] = [7]$$
*   **Path 2 ($p_2$):** $A \to C \to D$ with weights $w_{AC}=3, w_{CD}=3$.
    $$M_2 = [3] \otimes [3] = [3 + 3] = [6]$$
*   **Path 3 ($p_3$):** $A \to D$ (direct edge) with weight $w_{AD}=10$.
    $$M_3 = [10]$$

Thus, the set of morphisms is $\mathcal{M}_{AD} = \{ [7], [6], [10] \}$.

### 4. Computation of the Tropical Sum ($M^*$)
The objective is to find the tropical sum of all morphisms in $\mathcal{M}_{AD}$. This represents the infimum of the family of linear transformations in the 1-dimensional tropical modulespace:
$$M^* = \bigoplus_{M \in \mathcal{M}_{AD}} M$$
$$M^* = [7] \oplus [6] \oplus [10]$$

Applying the definition of tropical addition (the $\min$ operator):
$$M^* = [\min(7, 6, 10)]$$
$$M^* = [6]$$

### Final Result
The shortest path weight, transported into the algebraic structure of the target category $\mathcal{V}ect(\mathbb{R}_{\min})$, is represented by the $1 \times 1$ tropical matrix:
$$M^* = [6]$$
This result signifies that the "infimum of the family of linear transformations" from $F(A)$ to $F(D)$ is the value **6**, which corresponds to the weight of the path $A \to C \to D$.

## Final Result

To map the solution from the target category $\mathcal{V}ect(\mathbb{R}_{\min})$ back to the source category $\mathcal{G}_W$, we perform an inverse interpretation of the functor $F$. While $F$ is not strictly invertible (as multiple paths could map to the same weight), we can identify the preimage of the optimal morphism to determine the shortest path and its value.

### 1. Interpretation of the Target Result
In the target category, we found that the "infimum of the family of linear transformations" between $F(A)$ and $F(D)$ is the $1 \times 1$ tropical matrix $M^* = [6]$. 

*   **The Value:** In the tropical semiring, the scalar value $6$ represents the result of the $\oplus$ (min) operation over all available morphisms. In the source category $\mathcal{G}_W$, this corresponds to the **minimum total weight** among all possible paths from node $A$ to node $D$.
*   **The Morphism:** The matrix $M^* = [6]$ is the image of the path $p_2$ under the functor $F$. Specifically, $F(p_2) = [w(A \to C) + w(C \to D)] = [3 + 3] = [6]$.

### 2. Mapping Back to the Source Category
To provide the solution in the context of the original graph problem, we look for the path $p \in \text{Hom}_{\mathcal{G}_W}(A, D)$ such that $F(p) = M^*$.

*   **Preimage Identification:** 
    *   $F(p_1) = [7]$
    *   $F(p_2) = [6]$
    *   $F(p_3) = [10]$
    *   Since $M^* = [6]$, the corresponding path in the source category is **$p_2$**.

*   **Path Reconstruction:** The morphism $p_2$ in $\mathcal{G}_W$ is defined by the composition of edges $e_{CD} \circ e_{AC}$. This translates to the sequence of nodes: **$A \to C \to D$**.

### 3. Adjoint Interpretation
Because the functor $F$ maps paths to weights, the "inverse" process is essentially a search over the fiber of $F$ at the point of the tropical minimum. The tropical sum $\bigoplus$ in the target category acts as a selector that identifies the "least" morphism. Mapping this back to the source category identifies the **geodesic** (the shortest path) in the graph.

---

### Final Answer
The shortest path between node **A** and node **D** in the directed weighted graph is:

**Path:** $A \to C \to D$  
**Total Weight:** $6$

This was determined by finding the preimage of the tropical identity $M^* = [6]$ within the set of morphisms $\text{Hom}_{\mathcal{G}_W}(A, D)$, confirming that the path through node $C$ yields the minimum cost in the tropical linear system.
