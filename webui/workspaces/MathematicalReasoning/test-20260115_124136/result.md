# Solution

## Problem
Solve for x: 3x + 7 = 22

## Answer

$$x = 5$$

Simplify both sides of the equation to find the value of x.

## Key Steps

- Restate the linear equation 3x + 7 = 22 and identify x as the variable to be solved.
  - $3x + 7 = 22$
- Subtract 7 from both sides of the equation to isolate the term containing x.
  - $3x + 7 - 7 = 22 - 7$
- Simplify both sides of the equation by performing the subtraction.
  - $3x = 15$
- Divide both sides of the equation by 3 to isolate the variable x.
  - $\frac{3x}{3} = \frac{15}{3}$
- Simplify both sides of the equation to find the value of x.
  - $x = 5$
