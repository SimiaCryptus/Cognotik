This is a placeholder to demonstrate where queries should go now.

  Each research document owns its own folder: this file is `queries/<slug>/query.md`
  and every generated analysis file is a sibling of it:

  - `research.md` — research findings (`ops/process_query.op.md`)
  - `summary.md` — concise digest (`ops/summarize_research.op.md`)
  - `followup.json` — structured follow-up plan (`ops/research_followup.op.md`)
  - `followup.md` — generated patches (`ops/process_followup.op.md`)
  - `followup.<task-id>.md` — per-task doc-ops written by the UI
