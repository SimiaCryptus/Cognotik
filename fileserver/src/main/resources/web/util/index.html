House rules

    Every page here is served straight from this folder — no build step, no bundler. Doc-op paths and status locations are derived from the page URL, so keep a tool's folder: front-matter and its ROOT_HOPS constant in sync if you move it to a different depth.

    The bar at the top is the shared menubar from /app/menu.js (nav, filesystem IDE link, git, sessions, usage). Pass overrides through meta.menu in apps.js — e.g. { showGit: false, sessionsEndpoint: '/api/sessions?format=json' }. If the shared modules are not deployed the bar is simply omitted.
