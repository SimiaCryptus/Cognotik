## Getting Started 🚀

Welcome to **Cognotik**! You've just installed a comprehensive, open-source AI development platform that brings powerful agentic tools directly into your IDE. Let's get you set up and coding smarter in no time.

---

## 🔑 Open Source & Bring Your Own Key (BYOK)

Cognotik is 100% open source software, giving you complete transparency and control. With our "Bring Your Own Key" model, you:

- **Control Your Data**: Your code stays between you and your chosen AI provider
- **Manage Your Costs**: Pay providers directly at their rates
- **Choose Your Models**: Use any supported AI model that fits your needs
- **Ensure Privacy**: No intermediary servers or data collection

---

### Step 1: Obtain API Keys

To unlock Cognotik's full potential, you'll need API keys from one or more supported AI providers. Here are links to popular providers where you can register and obtain your keys:

- [OpenAI](https://platform.openai.com/)
- [Anthropic](https://www.anthropic.com/api)
- [Google](https://ai.google.dev/tutorials/setup) - **PSST!** _Free For Now!_
- [Groq](https://console.groq.com/) - **PSST!** _Free For Now!_
- [Perplexity AI](https://www.perplexity.ai/)
- [ModelsLab](https://modelslab.com/dashboard/)

---

### Step 2: Configure Your Plugin 🛠️

Once you have your API keys:

1. Open IntelliJ IDEA and navigate to **Settings > Tools > Cognotik**
2. Enter your API keys in the configuration panel under the appropriate provider fields
3. Select your preferred models and configure advanced settings as needed

---

### Step 3: Explore High-Level Agentic Tools 🤖

Cognotik focuses on **powerful agentic capabilities** that go beyond simple code completion. Our tools handle complex, multi-step workflows that require sophisticated reasoning and state management.

#### Editor Actions
- **Smart Paste**: Intelligently paste and transform code with AI assistance
- **Edit Selection**: Modify selected code based on natural language instructions
- **Code Chat**: Discuss and understand code with contextual AI insights

#### File & Project Actions
- **Generate Documentation**: Create comprehensive docs for entire projects
- **Create Unit Tests**: Generate test suites with edge cases and mocks
- **Refactor Codebase**: Apply consistent refactoring across multiple files
- **Generate Related Files**: Create complementary files (tests, configs, etc.)

#### Advanced Agentic Features
- **Task Runner**: Execute complex development workflows with AI orchestration
- **Multi-Step Patch**: Apply coordinated changes across your entire codebase
- **Auto-Fix Test Results**: Automatically diagnose and fix failing tests
- **Web Dev Assistant**: Scaffold complete web applications with AI guidance
- **Voice to Text**: Dictate code and commands hands-free

> **Note**: Many agentic features open in a web browser for complex interactions that require persistent state and sophisticated UI elements.
