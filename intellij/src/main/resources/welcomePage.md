## 🚀 Quick Start Guide

### 1️⃣ Get Your API Keys

Choose from our supported AI providers and obtain your API keys:

#### 🆓 Free Options (Great for Getting Started!)
- **[Google AI Studio](https://ai.google.dev/tutorials/setup)** - Generous free tier with Gemini models
- **[Groq](https://console.groq.com/)** - Ultra-fast inference with free tier
- **[AWS Bedrock](https://aws.amazon.com/bedrock/)** - Free tier with various models (use `{}` for default AWS credentials)

#### 💎 Premium Providers
- **[OpenAI](https://platform.openai.com/)** - GPT-4, GPT-3.5, DALL-E
- **[Anthropic](https://www.anthropic.com/api)** - Claude 3 family
- **[Perplexity AI](https://www.perplexity.ai/)** - Web-aware AI models
- **[ModelsLab](https://modelslab.com/dashboard/)** - Specialized models

### 2️⃣ Configure Cognotik

1. Navigate to **Settings → Tools → Cognotik**
2. Enter your API keys for chosen providers
3. Select default models for different tasks
4. Adjust temperature and other parameters to your preference

### 3️⃣ Start Using Powerful Features

Access Cognotik features through:
- **Right-click context menus** in the editor
- **Tools → Cognotik** menu
- **Keyboard shortcuts** (customizable in Settings)
- **Action search** (Ctrl/Cmd + Shift + A)

## 💡 Pro Tips

### Maximize Your Productivity
- **Combine with other tools**: Cognotik complements code completion assistants
- **Use voice commands**: Dictate code and instructions hands-free
- **Create templates**: Save common workflows for reuse
- **Leverage context**: Select relevant code before invoking actions

### Cost Optimization
- Start with free providers (Google, Groq) for experimentation
- Use cheaper models for simple tasks, premium for complex ones
- Monitor usage through provider dashboards
- Set up usage alerts to control spending

### Privacy & Security
- Your code stays between you and your chosen provider
- No telemetry or usage tracking by Cognotik
- API keys stored securely in IDE settings
- Option to use local models for sensitive projects
