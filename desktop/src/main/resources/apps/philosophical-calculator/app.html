1 Summarize Notes pending

Distill your raw notes into a thematic, conceptual summary organized by key ideas — not a chronological recap.

2 Draft Article pending

Generate a polished, coherent article or essay based on the summary, notes, and any instructions provided.

3 Update Article (Synthesize Lenses) pending

Weave insights from all analytical lenses back into the main article. Run this after completing one or more lenses.

4 Illustrate Article pending

Add inline AI-generated illustrations to the article. This modifies content.md in place.

✏️ Manual Article Editor

🚀 Quick Sequence

Run the core pipeline steps in sequence (Summarize → Draft). Use the Lenses tab to run individual analytical operations, then come back to run Update.

🔬 Lenses

Analysis Lenses surface insights that can be synthesized back via Update Article; Output Lenses produce standalone deliverables.

🔍 Analysis Lenses

These lenses analyze and explore your content from distinct intellectual perspectives. Their outputs feed back into the article via the Update Article pipeline step.

💡 Brainstorm pending

Generate a broad, divergent set of ideas, extensions, and applications.

⚖️ Dialectical pending

Thesis, antithesis, synthesis — explore contradictions and resolve them into higher-level understanding.

🏛️ Socratic Dialogue pending

Transform content into a rigorous Socratic dialogue that exposes assumptions and strengthens arguments.

👥 Perspectives pending

Analyze from multiple stakeholder viewpoints — differing priorities, concerns, and insights.

🎲 Game Theory pending

Identify players, strategies, payoffs, and equilibria, with payoff matrices and Nash equilibrium analysis.

🏛️ Historical Debate pending

Stage an in-character debate between historical figures, with rebuttals and an impartial moderator synthesis.

🧬 Unrunnable Protocol pending

Analyze the core concept through dense pseudo-code "Unrunnable Protocol" frameworks, audited against pattern worship.

📦 Output Lenses

These lenses transform your article into finished deliverables in different formats and styles.

🎯 Persuasive Essay pending

Reframe as a compelling persuasive essay using rhetorical techniques.

📖 Narrative pending

Dramatize the content into a compelling narrative with illustrations.

💬 Comic Book pending

Generate a comic book representation of the content.

🔧 Technical Tutorial pending

Precise technical breakdown with definitions, mechanisms, code snippets and worked examples.

🌐 HTML Webpage pending

Generate a standalone HTML webpage representation of the article.

🔬 Batch Lenses

Select which lenses to run, then execute them all sequentially.
