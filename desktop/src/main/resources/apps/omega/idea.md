# App Idea

Describe the DocOps application you want to build. Include:

- **Purpose**: What does the app do?
- **User Input**: What does the user provide?
- **Desired Output**: What should the app produce?
- **Pipeline Steps**: (Optional) Any specific processing stages you envision
- **Special Requirements**: Any specific task types, external research, iteration, etc.

## Example

> I want an app that takes a business idea and produces a complete pitch deck outline,
> competitive analysis (via web research), and a one-page executive summary.
