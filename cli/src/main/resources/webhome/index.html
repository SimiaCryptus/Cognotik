Cognotik File Server mounts one directory over HTTP and puts an agentic toolchain on top of it: browse and edit files, open a terminal, run DocOps and AutoFix, or ask a model to patch your code — all against the same workspace, with the rights of the user that started the process.

🧭 IDE view The full single-page app: file tree, editor, terminal, Git and the Tools menu (DocOps, AutoFix, Select Models…). /ui/ Disabled with --no-ui. 🗂 Classic listing A plain directory listing with uploads, per-file Modify, per-document Plan/Run links and a live task panel. /files/root/ ⚙ Settings Pick the smart and fast models and manage provider API keys. One selection re-binds DocOps, AutoFix and the patch chat. /home/settings.html

Capabilities

This is a permissive local mount by default: terminals and unrestricted child processes are on, and it binds to loopback. Start it with --secure to turn everything below off.

⚠ Arbitrary code execution is enabled on a non-loopback interface. Anyone who can reach this port can run commands as you.
