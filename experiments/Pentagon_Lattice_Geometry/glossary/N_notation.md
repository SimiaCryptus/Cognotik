# N. Notation and Symbols — Detailed Reference

This document provides an organized **symbol glossary** for the multi-sheeted n-gon
tiling project. Symbols are grouped by role (algebra, geometry, group/bundle,
spectrum, dimension, family). Each entry gives the symbol's meaning, typical use,
and pointer to the relevant section of the main glossary.

---

## Algebra and Number Theory

| Symbol                              | Meaning                                    | Notes                                                                                        |
| ----------------------------------- | ------------------------------------------ | -------------------------------------------------------------------------------------------- |
| $\mathbb{Z}$                        | Integers                                   | Standard.                                                                                    |
| $\mathbb{Q}$                        | Rational numbers                           | Field of characteristic 0.                                                                   |
| $\mathbb{R}$                        | Real numbers                               | Completion of $\mathbb{Q}$.                                                                  |
| $\mathbb{C}$                        | Complex numbers                            | Algebraic closure of $\mathbb{R}$.                                                           |
| $\mathbb{Q}(\sqrt{d})$              | Quadratic field                            | Degree 2 over $\mathbb{Q}$.                                                                  |
| $\mathbb{Q}(\sqrt{5})$              | Real quadratic field of $\sqrt{5}$         | Discriminant 5; the project's main field.                                                    |
| $\mathbb{Z}[\phi]$                  | Ring of integers of $\mathbb{Q}(\sqrt{5})$ | PID, UFD; elements $a + b\phi$.                                                              |
| $\mathbb{Z}[i]$                     | Gaussian integers                          | Norm $a^2 + b^2$; used in pinwheel constructions.                                            |
| $\mathbb{Q}(\zeta_n)$               | Cyclotomic field                           | Generated by primitive $n$-th root of unity.                                                 |
| $\phi$                              | Golden ratio                               | $(1 + \sqrt{5})/2 \approx 1.618$; fundamental unit.                                          |
| $\psi$                              | Galois conjugate of $\phi$                 | $(1 - \sqrt{5})/2 \approx -0.618 = -1/\phi$.                                                 |
| $\zeta_n$                           | Primitive $n$-th root of unity             | $e^{2\pi i / n}$.                                                                            |
| $\alpha$                            | Generic algebraic number                   | Used for an arbitrary irrational base.                                                       |
| $N(\cdot)$                          | Field norm                                 | Multiplicative: $N(xy) = N(x)N(y)$. For $\mathbb{Z}[\phi]$: $N(a + b\phi) = a^2 + ab - b^2$. |
| $\sigma$                            | Galois automorphism                        | $\sigma(\sqrt{d}) = -\sqrt{d}$.                                                              |
| $\text{Gal}(\mathbb{F}/\mathbb{Q})$ | Galois group                               | Automorphisms of $\mathbb{F}$ fixing $\mathbb{Q}$.                                           |
| $F_n$                               | Fibonacci number                           | $F_{n+1} = F_n + F_{n-1}$; $F_0 = 0, F_1 = 1$.                                               |
| $L_n$                               | Lucas number                               | Companion to Fibonacci; $L_{n+1} = L_n + L_{n-1}$, $L_0 = 2, L_1 = 1$.                       |

## Geometry

| Symbol                          | Meaning                          | Notes                                                                                  |
| ------------------------------- | -------------------------------- | -------------------------------------------------------------------------------------- |
| $\theta$                        | Interior angle                   | Of a polygon at a vertex. Pentagon: $108°$.                                            |
| $\delta$                        | Angular deficit                  | $2\pi - \sum \theta$ around a vertex. Pentagon: $36°$.                                 |
| $\alpha$                        | Dihedral angle                   | Of a polyhedron along an edge (3D analogue of $\theta$).                               |
| $P$, $P_0$                      | Polygon / polyhedron / seed tile | Capital $P$ for a generic polytope; $P_0$ for the seed.                                |
| $\mathcal{L}$                   | Projected vertex set / lattice   | Image of multi-sheeted vertices in $\mathbb{R}^n$.                                     |
| $\mathcal{M}$                   | Covering space                   | Multi-sheeted manifold above $\mathbb{R}^n$.                                           |
| $\pi$                           | Projection map                   | $\pi: \mathcal{M} \to \mathbb{R}^n$ (sheet → base). Also: ratio of circle to diameter. |
| $\chi$                          | Euler characteristic             | $\chi = v - e + f$ for polyhedra.                                                      |
| $E$                             | Edge set                         | $E = E_A \cup E_I$ (active ∪ inactive).                                                |
| $F$                             | Face set (3D)                    | Analogue of $E$ for faces.                                                             |
| $V$                             | Vertex set                       | Standard.                                                                              |
| $\Sigma$                        | Vortex set                       | Set of vortex vertices in $\mathbb{R}^n$.                                              |
| $\mathbb{R}^n \setminus \Sigma$ | Punctured space                  | Base of the multi-sheeted bundle.                                                      |

## Dimensions

| Symbol            | Meaning                            | Notes                                                      |
| ----------------- | ---------------------------------- | ---------------------------------------------------------- |
| $d$               | Generic dimension                  | Usually integer (ambient dimension).                       |
| $d_{\text{eff}}$  | Effective (connectivity) dimension | From volume scaling $V(r) \sim r^{d_{\text{eff}}}$.        |
| $d_{\text{spec}}$ | Spectral dimension                 | From $\rho(\lambda) \sim \lambda^{d_{\text{spec}}/2 - 1}$. |
| $d_w$             | Walk dimension                     | From $\langle \Delta x^2 \rangle \sim t^{2/d_w}$.          |
| $d_H$             | Hausdorff dimension                | Measure-theoretic dimension.                               |
| $d_B$             | Box-counting dimension             | Equals $d_H$ for self-similar fractals.                    |
| $r$               | Scale                              | BFS radius or continuous scale parameter.                  |
| $t$               | Time                               | Random walk step count or continuous time.                 |

The **Alexander–Orbach relation**: $d_{\text{spec}} = 2 d_{\text{eff}} / d_w$.

## Overloaded Symbols (Disambiguation)

Several symbols are unavoidably overloaded; the project relies on context:

- **$\pi$**: ratio circle/diameter, projection map, or fundamental group ($\pi_1$).
  Distinguished by subscript and context.
- **$\Delta$**: graph Laplacian or angular deficit. Typically typeset $\Delta$ (Laplacian)
  vs. $\delta$ (deficit), but both appear with $\Delta$ in some sources.
- **$\psi$**: Galois conjugate of $\phi$ (algebra) or wave function (physics). Use
  context.
- **$O$**: orthogonal group $O(n)$ vs. octahedral group $O$. Distinguished by
  arguments.
- **$\sigma$**: Galois automorphism, CA cell state, or general spin variable. Context.
- **$\alpha$**: generic algebraic number, dihedral angle, or coupling constant.
  Context.

## Typographical Conventions

- **Bold lowercase** ($\mathbf{x}$, $\mathbf{b}$) for vectors.
- **Italic uppercase** ($A$, $D$) for matrices.
- **Calligraphic** ($\mathcal{F}$, $\mathcal{G}$, $\mathcal{M}$) for high-level
  structures (families, graphs, manifolds).
- **Blackboard bold** ($\mathbb{Z}$, $\mathbb{Q}$, $\mathbb{R}$, $\mathbb{F}$) for
  number systems and fields.
- **Greek lowercase** for angles, parameters, group elements.
- **Greek uppercase** for groups ($\Gamma$, $\Sigma$, $\Delta$).
- **Sans-serif** or **fraktur** are avoided to keep notation portable.
