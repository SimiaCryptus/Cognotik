# Interpreter Module

This directory contains the core abstractions for code execution and runtime management within the Cognotik framework.

## CodeRuntime

The `CodeRuntime` interface defines the standard contract for executing code snippets across different programming languages. It allows the system to interact with various interpreters or compilers in a uniform way.

### Key Components

*   **Language Identification**: The `language` property identifies which programming language the runtime handles (e.g., "kotlin", "python").
*   **Symbol Table**: The `symbols` map provides the execution context, allowing variables to be passed into the runtime environment.
*   **Execution**: The `run(code: String)` method is the primary entry point for executing logic and retrieving results.
*   **Validation**: The `validate(code: String)` method allows for syntax checking and pre-execution verification without actually running the code.

### Extension Points

The interface provides default implementations for wrapping logic:

*   **`wrapCode(code: String)`**: Can be overridden to automatically add imports, headers, or boilerplate code to every execution.
*   **`wrapExecution(fn: Supplier<T?>)`**: Provides a lifecycle hook to wrap the execution process, useful for:
    *   Setting up thread-local contexts.
    *   Performance monitoring and logging.
    *   Security sandboxing.
    *   Resource management.

### Strategy Pattern

`CodeRuntime` extends `EnabledStrategy`, allowing specific runtime implementations to be dynamically enabled or disabled based on configuration or environment capabilities.

## Usage Example

Implementations of this interface are typically used by the interpreter engine to evaluate code blocks generated by LLMs:

```kotlin
val result = codeRuntime.run("println(\"Hello, World!\")")
